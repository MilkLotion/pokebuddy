# 무대 말풍선을 아이콘으로 (2026-09-29, 맥)

## 설계

- 사용자 지시(2026-09-29): "말풍선들 배고파랑 주웠어 이런거 하지말고, 말풍선에 아이콘들 넣어. 배고프면 고기모양 아이콘(만화고기) 많이배고프면 고기 3개, 아이템은 그 아이템 모양. 포인트는 금화모양 이런식으로 말이야."
- 결정 1: 무대 말풍선에 글자를 쓰지 않고 아이콘을 담는다.
- 결정 2: 배고픔은 만화 고기 1개, 매우 배고픔은 고기 3개다.
- 결정 3: 줍기에서 도구·진화용 도구는 그 도구 그림, 포인트는 금화다.
- Claude 판단(사용자 확인 전): 줍기에서 포켓몬은 데려온 포켓몬의 그림을 담는다. 원격 그림을 못 받으면 말풍선을 띄우지 않는다.
- 고기와 금화는 저장소의 도트 그림 스크립트(커밋 `6905e6a`) 방식으로 새로 그린다. 원작 그림을 저장소에 넣지 않는다.
- 되풀이 주기(배고픔 10분, 매우 배고픔 5분)와 말풍선 모양·위치는 유지한다.

## 작업

- 무대 말풍선에 글자 대신 아이콘을 넣었다. 배고픔 고기 1개, 매우 배고픔 고기 3개. 줍기는 도구 그림, 금화, 포켓몬 초상.
- 포켓몬은 PokeAPI 초상을 쓴다. 무대 도트(PMD)는 박스로 간 종이면 받아 둔 그림이 없기 때문이다. 렌더러가 불투명 부분만 잘라 22px 칸에 맞춘다.
- 말풍선 모양(높이 28, 반경 12, 꼬리)은 그대로다. 아이콘 칸은 22×22이고 보간 없이 그린다.
- 새 IPC `stage:icons`로 그림을 먼저 보내고 프레임에는 열쇠만 싣는다. 그림을 못 구하면 말풍선을 띄우지 않는다. CSP와 sandbox는 그대로다.
- i18n `bubble.*` 4개를 지웠다.
- 그림: `assets/items/meat.png`, `assets/items/coin.png`. `scripts/build-item-art.cjs`에 더했다(`node scripts/build-item-art.cjs meat coin`). 기존 7장은 다시 만들어도 바이트가 같다.
- 문서: `docs/specs/ui-components.md` C-20, `docs/specs/game.md`.
