# worklog-mac — 맥에서 쓴 임시 작업 기록

이 컴퓨터에는 `worklog/`(git 제외)가 없다. 그래서 이 폴더에 임시로 적는다(2026-09-29 사용자 지시). 사용자가 메인 작업 PC에서 `worklog/`로 옮겨 정리한다.

- `scripts/check-docs.cjs`는 이 폴더를 `문서 루트 위치 오류: docs/worklog-mac`으로 잡는다. 옮기면 사라진다.
- 공개 문서는 이 폴더를 링크하지 않는다.
