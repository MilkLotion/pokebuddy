# 용어사전

적용 범위: 사용자 화면과 제품 설명의 용어다.

## 읽는 기준

이 사전은 각 용어의 현재 이름과 뜻을 적는다.
`[스펙 미확정]`은 이름이나 세부를 아직 정하지 않은 항목이다. 각 항목에 미정 범위를 적는다.
결정은 [현재 설계](design.md)를 따른다. 기능 조건은 [게임 규칙](specs/game.md)을 따른다. 수치는 [밸런스 수치](specs/balance.md)를 따른다. 이 사전에서 새 수치를 정하지 않는다.

## 번호 체계

문서와 코드의 번호는 세 종류다. 번호마다 가리키는 대상이 다르다.

**단계 번호 S0~S6** — 개발 단계다. 기능 묶음을 만든 순서다.

| 단계 | 기능 이름 | 비고 |
|---|---|---|
| S0 | 설계 | |
| S1 | 기반 — 저장·잠금·mailbox·명령 처리기 | |
| S2 | 무대 — 클릭·끌기·놓아 둔 자리 | |
| S3 | 육성(옛 규칙) — 성격·배고픔·기분·친밀도·토큰 | S5 규칙으로 바뀌었다 |
| S4 | 옛 상점·진화 — 해금·파티 칸·먹이·진화·모습 선택 | S5 규칙으로 바뀌었다 |
| S5 | 새 게임 규칙·설정창 — 개체·박스·알·가방·도감·업적과 설정창 | |
| S6 | 배포 — 패키징·게시·자동 시작 | |

**저장 형식 v1~v3** — `save.json` 의 `v` 값이다. 게임 규칙이 크게 바뀔 때 올렸다.

| 형식 | 쓰던 단계 | 지금 역할 |
|---|---|---|
| v1 | 첫 시제품 | 읽을 때 v2 로 옮긴다 |
| v2 | S1~S4 | 읽을 때 v3 로 옮긴다. 원본은 `save.json.v2.bak` 에 남긴다 |
| v3 | S5 | 앱이 읽고 쓰는 유일한 형식이다 |

저장 v3 는 S5 규칙을 돌리는 형식이다. 그래서 "S5" 와 "v3" 는 같은 작업을 가리킬 때가 많다. 코드 파일 이름에는 번호를 붙이지 않는다. 저장 형식 자체를 가리키는 이름(`SaveV3`, `SAVE_V3_RULES`, `save/v3.ts`, `save/migrate-v3.ts`)만 번호를 쓴다. 옛 v1·v2 파일을 읽는 코드는 `save/legacy.ts` 다.

**Figma 판 번호** — 문서의 "디자인 시스템 v2", "v2 검수"는 S5 화면을 그린 Figma 2판이다. 저장 v2 와 관계가 없다. V2-01~V2-12 는 Figma 2판에서 찾은 디자인 문제 번호다.

## 포켓몬과 파티

규칙은 [도감 등록과 파티 소환](specs/game.md#3-도감-등록과-파티-소환)을 따른다.

| 명칭 | 의미와 사용 규칙 |
|---|---|
| 포켓몬 | 사용자가 도감에서 확인하거나 파티에 소환하는 대상이다. 종과 개별 육성 기록은 문맥에 따라 구분한다. |
| 종 | 포켓몬 종류를 구분한다. 같은 종의 개체를 여러 마리 보유할 수 있다. 동시에 파티에 배치할 수 있다. |
| 개체 | 사용자가 개별적으로 돌보는 포켓몬 한 마리다. 친밀도는 개체별로 관리한다. 종과 구분한다. |
| 파티 | 소환한 포켓몬을 배치하는 전체 구성이다. 새 게임은 2칸이다. 포인트 구매로 2칸, 업적으로 2칸을 추가해 최대 6칸을 사용한다. |
| 파티 칸 | 포켓몬 한 마리를 배치하는 자리다. 파티 전체와 구분한다. |
| 빈 칸 | 사용할 수 있지만 포켓몬을 배치하지 않은 파티 칸이다. |
| 잠긴 칸 | 아직 사용할 수 없는 파티 칸이다. 소환 대상으로 선택할 수 없다. 잠긴 칸은 항상 뒤쪽에 있다. 상점에서 파티 칸을 사거나 파티 칸 업적 보상을 받으면 첫 잠긴 칸이 열린다. 포켓몬을 주는 업적 보상은 칸을 열지 않는다. |
| 도감 | 전체 종과 각 종의 등록 상태를 확인하는 화면이다. |
| 도감 등록 | 해당 종을 소환할 수 있는 상태다. 도감 전체 목록에 보이는 것과 구분한다. |
| 미등록 | 도감에 표시되지만 아직 소환할 수 없는 상태다. |
| 소환 | 도감에 등록된 종을 빈 파티 칸에 배치하는 것이다. |
| 교체 | 선택한 파티 개체와 박스 개체를 한 번에 맞바꾸는 것이다. 같은 종끼리도 교체할 수 있다. |
| 소환 해제 | 파티 칸을 비우는 것을 가리키는 옛 용어다. 지금은 박스 보관이 대신한다. 버튼 문구는 `박스에 보관`이다. 도감 등록과 육성 기록은 보존한다. |
| 재소환 | 등록된 종을 다시 소환하는 동작을 설명하는 말이다. 재소환에 따로 주는 보상은 없다. 박스에서 다시 꺼내도 개체의 기록은 그대로다(`src/party/placement.ts`). 진화하면 종만 바뀌고 개체의 나머지 값은 그대로다. |
| 숨기기 | 파티 배치를 유지하면서 포켓몬 표시만 끄는 동작이다. 숨겨도 육성을 유지한다. |
| 박스 보관 | 개체를 파티에서 빼고 보관하는 것이다. 포인트 적립을 멈춘다. 친밀도·배고픔·남은 버프 시간을 보존한다. 숨기기와 구분한다. |
| 박스 | 파티에 배치하지 않은 보유 개체를 보관하는 곳이다. 게임 규칙상 보유 개체 수 제한이 없다. 설정창의 박스 메뉴에서 본다. 한 박스는 30칸이며 여러 박스를 넘겨 본다. 모두 차면 새 박스가 생긴다. 돌보미집도 박스 메뉴 안에 있다. |
| 꺼내기 | 볼에 있는 숨긴 파티 개체를 화면에 표시하는 조작이다. 새로 파티에 들어온 개체는 꺼낸 상태로 들어온다. 부화·상점 구매·박스에서 배치·교체가 모두 같다(`src/party/placement.ts`). 파티 이동과 구분한다. 개체 상세의 닫힌 볼 토글로 한다. 토글의 접근성 이름은 `꺼내기`다. |
| 볼에 넣기 | 꺼낸 파티 개체를 바탕화면에서 숨기는 조작이다. 개체는 파티에 남고 시간 진행도 그대로다. 개체 상세의 열린 볼 토글이나 바탕화면 우클릭 메뉴 `볼에 넣기`로 한다. 코드의 `party.hide`·`hidden` 이다. 박스 보관과 구분한다. |
| 다시 표시 | 숨긴 파티 포켓몬의 표시를 다시 켜는 동작이다. 새 소환이나 교체를 뜻하지 않는다. |

숨김 상태는 이미지 영역 우측 위의 작은 닫힌 몬스터볼로 표시한다. 상태 조작에는 툴팁과 접근성 이름을 제공한다.
도감 해금에는 개별 포켓몬의 레벨을 사용한다. 해금 후 입수처는 종별로 구분한다.

| 용어 | 의미 |
|---|---|
| 레벨 | 개별 포켓몬의 성장 단계다. 경험치로 오른다. 도감 해금 조건에 사용한다. 친밀도와 별도다. |
| 입수처 | 해당 종의 개체를 실제로 얻는 방법이다. 상점 구매와 진화 전용 등을 종별로 구분한다. |
| 도감 해금 수 | 보유 여부와 관계없이 해금된 서로 다른 도감 항목의 수다. 일반 폼과 리전폼은 각각 1종으로 센다. 초기 후보와 레벨 조건으로 해금한 미진화 종도 포함한다. 같은 항목의 중복 개체는 종 수를 늘리지 않는다. |
| 도감 항목 | 해금과 종 수 집계의 단위다. 일반 대검귀 `503`과 히스이 대검귀 `503-1`은 별도 항목이다. 개체 ID와 구분한다. |
| 수집 난이도 | 종별로 지정하는 1~5 단계다. 랜덤알 부화 추첨의 공통 가중치를 결정한다. 상점의 종 지정 구매 가격도 결정한다(2026-09-29 사용자 결정). 1은 얻기 쉬운 쪽, 5는 얻기 어려운 쪽으로 표기한다. 난이도 값은 확률이나 가중치 수치 자체가 아니다. |
| 알 전용 | 알에서만 얻고 상점에서는 팔지 않게 지정한 종의 입수 방식이다. 일반 알(랜덤알·태고의돌)에서 얻는 종은 해금 뒤 상점에서도 판다(2026-09-29 사용자 결정). 그래서 지금 알 전용 종은 없다. 알 전용 종을 새로 지정하려면 이 상점 판매 규칙의 예외로 설계한다. 종 지정 구매와 구분한다. |
| 특수 기믹 전용 | 지정한 특수 조건이나 행동으로만 얻는 종의 입수 방식이다. 일반 구매와 랜덤알에서 제외한다. 세부 기믹은 `[스펙 미확정]`이다. |
| 진화 전용 | 기존 개체를 진화시켜야 얻을 수 있는 종의 입수 방식이다. 상점 구매와 구분한다. 진화 전용 종은 상점에서 팔지 않는다. 예: 잠만보는 먹고자에서 진화해 얻는다(2026-09-29 사용자 결정). |
| 단일 포켓몬 | 해당 저장에서 딱 한 번만 획득할 수 있도록 지정한 종이다. 전설·준전설·환상·울트라비스트 98종이다. 현재 보유 수가 아닌 획득 이력으로 제한한다. 일반 알에서는 얻을 수 없고 단일 포켓몬 알에서만 나온다. 다른 허용 입수처가 여러 개여도 총 획득 제한을 공유한다. 지정한 진화 계열은 같은 `sid`의 한 개체로 진행 상태를 공유한다. 해당 계열에서 한 종만 꺼낼 수 있다. |

## 튜토리얼과 가이드북

| 용어 | 의미와 사용 규칙 |
|---|---|
| 튜토리얼 | 기능 이용 시 조작을 알려주는 단계별 설명이다. 닫기와 스킵 후 해당 튜토리얼을 다시 표시하지 않는다. 다시보기 기능은 제공하지 않는다. 문서와 화면에서 튜토리얼을 `안내`로 부르지 않는다. 개체 상세 튜토리얼은 파티 개체를 파티 상세 기기 창에 처음 띄우면 5단계로 나온다. 화면 튜토리얼은 설정 모달의 `화면` 탭을 열면 나온다. 기능별 튜토리얼(성장·포인트·파티·가방·진화·도감·교환·사용자)은 [새 기능 튜토리얼](specs/game.md#새-기능-튜토리얼)을 따른다. |
| 코치마크 | 튜토리얼을 보여 주는 방식이다. 화면을 어둡게 하고 알려줄 대상만 밝게 남긴 뒤, 대상 옆 말풍선에 설명을 둔다. 설정창, 파티 상세 기기 창, 바탕화면(첫 돌봄)에 쓴다. 튜토리얼이 떠 있으면 말풍선 단추, 그 단계의 목표 행동, `✕` 만 받는다. 규칙은 [게임 규칙](specs/game.md)의 튜토리얼 절을 따른다. |
| 가이드북 | 사용자가 필요할 때 설정창 안에서 보는 사용법 화면이다. 설정 모달의 `가이드북` 행에서 연다. 모달 안에서 화면이 바뀌고 `‹ 설정`으로 돌아간다. 주제는 돌봄, 상점과 알, 파티와 박스, 진화, 업적이다. 튜토리얼을 재실행하지 않는다. 게임 조작이나 보상 지급을 실행하지 않는다. |
| 설명서 | 저장소 문서 `docs/guide.md` 다. 설치, 게임 방법, 설정, 문제 해결을 담는다. CLI 명령과 빌드·배포는 `docs/contributing/development.md`, 동작 원리는 `docs/specs/companion.md` 에 둔다. 앱 안의 가이드북과 다르다. |

## 육성과 보상

관련 규칙은 [성격과 육성](design.md#성격과-육성), [저장 타입](../src/shared/types.ts), [상태 규칙](../src/state/rules.ts)에 있다.

| 용어 | 의미와 사용 규칙 |
|---|---|
| 성격 | 포켓몬의 움직임과 상태에 영향을 주는 분류다. 원작 25개 성격을 사용한다. 타입이나 특성과 구분한다. |
| 친밀도 | 포켓몬별로 누적하는 육성 수치다. 경험치와 별도다. 현재 값이 높을수록 포인트 적립 간격이 짧아진다. 포인트 적립으로 소모하지 않는다. |
| 경험치 | 개체의 레벨을 최대 100까지 올리는 수치다. 친밀도와 별도로 관리한다. 경험사탕으로 얻는다. |
| 경험사탕 | 개체에 경험치를 주는 도구다. XS·S·M·L·XL 5종이다. 상점 구매와 업적 보상으로 얻는다. 파티와 박스의 보유 개체 모두에게 직접 사용할 수 있다. 숨김 여부는 사용을 제한하지 않는다. 가격과 효과량은 [밸런스 수치](specs/balance.md#성장)를 따른다. |
| 이상한사탕 | 사용한 개체의 레벨을 1 올리는 도구다. 새 레벨의 경험치 진행은 0부터 시작한다. 파티와 박스의 보유 개체 모두에게 사용할 수 있다. 숨김 여부로 제한하지 않는다. 100레벨에서는 사용할 수 없고 소비하지 않는다. 상점 구매와 업적 보상으로 얻는다. 가격은 [밸런스 수치](specs/balance.md#가격)를 따른다. |
| 배고픔 | 포켓몬이 배고픈 정도를 부르는 말이다. 만복도가 낮은 구간의 이름(배고픔·매우 배고픔)으로 쓴다. 옛 저장의 `hunger` 값은 높을수록 배고프다. 이 값은 [V2 → V3 변환 규칙](specs/modules.md#v2--v3-변환-규칙)에 따라 만복도로 옮긴다. |
| 만복도 | 배부른 정도를 나타내는 수치다. 최대이면 먹이를 줄 수 없다. 프리미엄먹이는 최대까지 채운다. 구간과 감소량은 [밸런스 수치](specs/balance.md#만복도와-돌봄)를 따른다. |
| 기분 | 포켓몬의 현재 기분을 나타내는 수치다. 친밀도와 달리 오르내릴 수 있다. 돌보면 오르고 시간이 지나면 내려간다. 보이기만 하고 다른 수치를 바꾸지 않는다. 수치는 [밸런스 수치](specs/balance.md#기분)를 따른다. |
| 돌봄 | 밥 주기와 놀아주기 같은 상호작용을 묶어 설명하는 말이다. 각 동작의 효과와 제한은 상태 규칙을 따른다. 포켓몬에게만 쓴다. 알 돌봄은 2026-09-28 삭제했다. |
| 밥 주기 | 대상 개체의 만복도를 높이는 돌봄 동작이다. 먹이 상품 구매와 구분한다. |
| 기본먹이 | 무료로 무제한 제공하는 먹이다. 만복도를 조금 회복한다. 최대 만복도이거나 밥 주기 쿨타임 중이면 사용할 수 없다. 회복량은 [밸런스 수치](specs/balance.md#만복도와-돌봄)를 따른다. |
| 밥 주기 쿨타임 | 밥 주기를 다시 사용할 때까지 기다리는 시간이다. 개체별로 적용하며 같은 개체의 기본먹이와 프리미엄먹이가 공유한다. 대기 중에는 해당 개체에게 먹이를 줄 수 없다. 진행과 정지는 [실행 상태별 시간](specs/game.md#실행-상태별-시간)을 따른다. 박스 보관 중에는 남은 시간을 보존한다. 길이는 [밸런스 수치](specs/balance.md#만복도와-돌봄)를 따른다. |
| 프리미엄먹이 | 상점에서 구매하는 먹이다. 대상의 만복도를 최대까지 채우고 친밀도 증가량 버프를 준다. 같은 먹이의 재사용은 버프 시간을 갱신한다. 최대 만복도에서는 사용할 수 없다. 가격·배율·지속시간은 [밸런스 수치](specs/balance.md)를 따른다. |
| 배고픔 상태 디버프 | 배고픔에 따라 새로 얻는 친밀도 증가량이 줄어드는 효과다. 누적 친밀도를 깎지 않는다. 파티 칸 오른쪽 위 상태 배지가 디버프 배지다. 표시 명칭은 "배고픔"·"매우 배고픔"이다. 다른 디버프 종류는 `[스펙 미확정]`이다. |
| 놀아주기 | 포켓몬과 놀아주는 돌봄 동작이다. 기분과 친밀도에 영향을 준다. |
| 오래 놀아주기 | 놀아주기 상태가 남은 동안 쿨타임마다 이어서 놀아줘 3중첩이 된 것이다. 그러면 오래 놀아주기 버프가 켜진다. 버프는 놀아준 한 마리의 친밀도 증가량을 높이며 프리미엄먹이 버프보다 효과가 낮다. 빠른 연속 클릭과 구분한다. `콤보`라는 이름은 쓰지 않는다. 시간은 [밸런스 수치](specs/balance.md#버프와-친밀도)를 따른다. |
| 장난감 | 놀아주기에 쓰는 도구다. 반응 애니메이션은 일반 놀아주기와 같고 파티클 같은 효과를 더한다. 1회성이며 한 번 놀아주면 1개를 소비한다. 가방에서 드래그해 포켓몬 위에 드롭하여 사용한다. 오래 놀아주기 버프와 같은 버프를 준다. 가격은 [밸런스 수치](specs/balance.md#가격)를 따른다. |
| 포인트 | 구매에 사용하는 게임 재화다. 친밀도와 구분한다. |
| 포인트 적립 | 파티 개체가 각자의 현재 친밀도에 따른 시간 간격으로 포인트를 얻는 것이다. 숨겨도 파티 배치를 유지하면 적립한다. 친밀도 증가량의 일회성 보상과 구분한다. |
| 줍기 | 바탕화면의 포켓몬이 가끔 포인트·도구·진화용 도구·포켓몬을 주워 오는 것이다(2026-09-29 사용자 결정 "포켓몬들이 움직이다가 낮은확률로 아이템/포켓몬 획득"). 포켓몬마다 따로 판정한다(2026-09-29 사용자 결정). 바탕화면에 나와 깨어 있는 시간만 센다는 조건은 제안이다. 사용자가 확인하기 전이다. 포인트 적립·상점 구매와 구분한다. 알림 배너의 제목도 `줍기`다. 조건은 [게임 규칙](specs/game.md#줍기), 수치는 [밸런스 수치](specs/balance.md#줍기)를 따른다. |
| 토큰 | 연결한 CLI에서 읽는 사용량 단위다. 게임 재화나 Figma 디자인 토큰과 구분한다. |
| 작업 시간 | 연결한 에이전트가 작업하는 시간이다. 모든 CLI 의 작업 적립에 쓴다. 단순히 앱을 켜 둔 시간과 구분한다. |
| 진화 | 조건을 충족한 같은 개체가 다음 단계로 성장하는 동작이다. 한 단계씩 직접 선택한다. 확정한 개체 정보는 유지한다. 세부 조건은 [상세와 진화](specs/game.md#4-상세와-진화)를 따른다. |
| 리전폼 | 진화 결과에서는 종별로 지정한 조건에 따라 정해지는 지역별 폼을 뜻한다. 일반 폼과의 자유로운 외형 변경을 뜻하지 않는다. |
| 이로치 | 같은 개체의 색상 상태다. 진화 후에도 유지한다. 해당 도감 항목에 획득 여부를 기록한다. 일반색으로 복귀해도 획득 기록은 남는다. 해금 종 수는 늘리지 않는다. 알의 낮은 확률 또는 상점 약 사용으로 얻는다. |
| 모습이 바뀌는 약 | 기존 개체를 이로치로 바꾸는 상점 상품이다. 1회 소모품이다. 가격은 [밸런스 수치](specs/balance.md#가격)를 따른다. |
| 돌아오는 약 | 기존 개체를 일반색으로 되돌리는 0원 상점 상품이다. |

## 구매와 사용

부화의 상태 용어는 [부화 준비와 결과](specs/game.md#부화-준비와-결과)을 따른다. `부화 가능`은 준비 시간이 끝나 직접 열 수 있는 상태다. `부화 완료`는 직접 열어 개체를 얻은 상태다. 두 상태를 구분한다.

| 업적 용어 | 의미 |
|---|---|
| 업적 달성 | 정해진 조건을 충족한 상태다. 보상 수령과 구분한다. |
| 업적 보상 수령 | 업적창에서 사용자가 보상을 받는 동작이다. 보상은 파티 칸이나 포켓몬 한 마리다. 파티 칸 보상은 수령한 뒤 열린다. 포켓몬 보상은 수령한 뒤 새 개체가 파티나 박스에 들어온다. 업적마다 한 번만 받는다. 받지 않은 보상은 기한 없이 미수령 상태로 남는다. |
| 업적창 | 달성한 업적의 보상을 받는 모달이다. 설정창 탭 줄 오른쪽의 업적창 아이콘이나 알림 배너의 `바로가기`로 연다. 닫으면 보던 탭으로 돌아간다. 미수령 보상이 있으면 아이콘에 dot를 표시한다. |
| 업적 배너 | 업적 달성을 알리는 작은 배너다. `업적 달성` 제목, 업적 표시와 이름, `바로가기` 버튼으로 구성한다. `바로가기`는 해당 업적의 수령 화면으로 이동한다. 배너에서 보상을 지급하지 않는다. 화면 우측 아래에 한 번 표시한다. 업적 알림과 같은 것이다. |

친밀도·포인트·경험사탕의 역할은 [친밀도와 경험치의 역할](specs/game.md#친밀도와-경험치의-역할)을 따른다.

상점 규칙은 [현재 상점 설계](design.md#상점)와 [상점과 가방](specs/game.md#6-상점과-가방)을 따른다.

| 용어 | 의미와 사용 규칙 |
|---|---|
| 해금 | 제한을 풀어 이용할 수 있게 되는 것이다. 종의 구매 조건인지 파티 칸의 사용 조건인지 대상을 적는다. 도감 등록과 같은 뜻으로 쓰지 않는다. |
| 상점 | 포인트로 상품을 구매하는 화면이다. 구매와 사용을 분리한다. |
| 가방 | 획득한 도구를 종류별로 보관하고 직접 사용하는 공통 화면이다. 칸 수와 종류별 보유 수량은 제한하지 않는다. 상점 구매로는 도구 한 종류를 999개까지만 채운다. 사탕 6종은 획득 경로와 관계없이 보관한다. 알은 가방에 넣지 않고 구매 직후 돌보미집에 배치한다. |
| 도구 | 가방에 보관한 뒤 대상 포켓몬을 골라 사용하는 상품 분류다. |
| 구매 | 포인트를 지불하고 상품을 얻는 동작이다. 구매 결과는 상품 계약을 따른다. |
| 사용 | 가방에서 도구의 대상과 옵션을 골라 효과를 적용하는 동작이다. 소모 규칙은 개별 상품에서 정한다. |

## 화면과 설정

화면 구조는 [화면 구조](specs/game.md#2-화면-구조)와 [설정과 연결](specs/game.md#7-설정과-연결)을 따른다.

| 용어 | 의미와 사용 규칙 |
|---|---|
| 설정창 | 파티 / 박스 / 도감 / 상점 / 가방 / 교환 탭과 헤더의 업적창·설정·우편함·유저 아이콘을 담는 창이다. 코드 식별자 `manage` 는 이 창이다. 문서에서 "관리 창"이라고 쓰지 않는다. |
| 파티 상세 기기 창 | 설정창 옆에 붙어 뜨는 개체 상세 창이다. 파티 카드나 박스 칸을 누르면 뜬다. 도감 기기 창과 같은 방식이다. 구현은 `src/main/pet-window.ts`·`src/renderer/pet.ts` 다. 규칙은 [파티 상세 기기 창](specs/game.md#파티-상세-기기-창)을 따른다. |
| 돌보미집 | 알을 최대 6개 배치하는 메뉴다. 각 알의 타이머를 개별 관리한다. 알은 데스크톱 놀이공간에 배치하지 않는다. 박스 메뉴 안에 둔다. |
| 설정 | 설정창 헤더의 설정 아이콘(톱니바퀴)으로 여는 모달이다. 일반 항목과 화면 항목을 관리한다. 설정창 전체와 구분한다. |
| 우편함 | 설정창 헤더의 봉투 아이콘으로 여는 모달이다. 운영자가 보낸 편지를 읽고 선물을 받는다. 코드 이름은 `mail` 이다. CLI 명령 통로 `mailbox` 와 다르다. 규칙은 [우편함](specs/game.md#우편함)을 따른다. |
| 편지 | 우편함의 글 한 통이다. 선물을 담을 수 있다. 선물이 없는 편지는 공지 편지다. 선물을 받은 뒤에도 편지는 남는다. |
| 선물 | 편지에 담긴 도구나 포인트다. `받기` 로 한 번에 모두 받는다. 로그인한 계정만 받는다. 파티와 박스 사이의 `교체`, 친구 `교환`과 다르다. |
| 사용자 | 설정창 헤더의 유저 아이콘으로 여는 모달이다. 계정(로그인·클라우드 저장)과 CLI 연결을 관리한다. |
| 연결 | CLI의 활동을 앱에서 감지하도록 연결하는 기능이다. 훅 연결 상태와 사용량 감지 상태를 구분한다. |
| 포켓몬 표시 | 옛 '무대 표시' 명칭을 대체한다. 화면 문구에 '무대'라는 말을 쓰지 않는다. |
| 놀이공간 | 포켓몬이 활동하는 영역이다. `모든 화면`·`한 화면`·`영역 지정` 중에서 고른다. 기본은 주 화면 하나다. 내부 `stage` 식별자와 구분한다. |
| 고스트 모드 | 켜면 포켓몬 위를 클릭해도 뒤의 창이 눌린다. 설정 키는 `clickThrough` 다. |
| 동반자 | 기기당 하나 떠 있는 포켓몬 표시 앱이다. 내부 식별자는 `companion`이다. 실행 방식은 이것 하나다. 화면 문구에는 모드 이름을 쓰지 않는다. |

놀이공간과 먹이 규칙은 [일상 사용 계약](specs/game.md#일상-사용-계약)을 따른다. `규토리`는 프리미엄먹이의 이름 후보다. 상품명으로 채택하지 않았다. `[스펙 미확정]`
실행 명령은 `pokebuddy companion`이다.

## 내부 UI 자산 용어

이 절은 화면을 만드는 사람이 사용하는 용어다. 사용자에게 표시할 명칭과 구분한다.

| 용어 | 의미와 식별자 |
|---|---|
| 타입 배지 | 포켓몬 타입 이름을 색상 배경 위에 표시하는 UI 원자다. v2 자산은 `Type Badge` `118:134`다. |
| 타입 태그 | 주 타입과 보조 타입의 배지 목록이다. `Traits` 안의 두 `Type Badge` 인스턴스로 구성한다. 보조 타입이 없으면 숨긴다. |
| 타입·성격 조합 | 내부 자산 `Traits` `119:969`의 설명이다. 원작의 특성 기능을 뜻하지 않는다. |

## 교환

| 용어 | 의미와 사용 규칙 |
|---|---|
| 교환 | 친구와 포켓몬을 한 마리씩 맞바꾸는 것이다. 파티와 박스 사이의 `교체`와 구분한다. |

## 제외 항목과 저장 보존

별명과 자유로운 모습 선택 기능은 제공하지 않는다. 이름은 종 이름을 표시한다. 이로치 색상 변경 약은 [별도 계약](specs/game.md#이로치와-색상-변경-약)을 따른다.
기존 저장의 `nick` · `look` 필드는 `legacy`에 보존한다. 기존 이로치 권리(`shiny:<개체 식별자>`)도 `legacy`에 보존한다. 그 밖의 구매 권리는 [V2 → V3 변환 규칙](specs/modules.md#v2--v3-변환-규칙)을 따른다.
파티 밖 개체는 박스에 보관한다. 규칙은 [파티 표시와 박스 보관](specs/game.md#파티-표시와-박스-보관)을 따른다.

## 도구와 알 용어

| 용어 | 의미와 사용 규칙 |
|---|---|
| 민트 | 성격을 바꾸는 도구다. 한 종류다(2026-09-29 사용자 결정). 쓰면 원작 25 성격 가운데 지금 성격이 아닌 성격을 고른다. 성격 이름을 붙인 민트(고집민트·성실민트 등)는 옛 이름이며 쓰지 않는다. 가격은 [밸런스 수치](specs/balance.md#가격)를 따른다. |
| 진화의돌 | 원작에서 돌로 진화하는 종의 진화 조건 도구다. 상점에서 구매해 가방에서 사용한다. 진화용 도구 목록은 `data/evo-items.json`을 따른다. 가격은 [밸런스 수치](specs/balance.md#가격)를 따른다. |
| 태고의돌 | 화석 포켓몬만 나오는 전용 알이다. 겉모습은 돌이며 상점의 알 분류에서 판다. 돌보미집 배치와 준비 시간은 랜덤알과 같다. 진화 전 10종과 진화하지 않는 5종이 나온다. 화석 진화형은 진화로 얻는다. 이로치 확률은 랜덤알과 같다. |
| 단일 포켓몬 알 | 랜덤준전설알·랜덤울트라비스트알·랜덤패러독스알·랜덤환상알·랜덤전설알. 그 분류의 아직 얻지 않은 단일 포켓몬이 나온다. 랜덤알을 열 때 낮은 확률로 나오고, 상점에서도 판다. 돌보미집 배치와 준비 시간은 랜덤알과 같다. |
| 랜덤알 | 해금한 종 중 알 입수처가 허용된 종을 얻는다. 진화 전용 종은 제외한다. 진화 전 종이 있는 종도 제외하며 첫 선택 후보는 예외다. 준비 시간이 끝나면 직접 연다. 확률과 준비 시간은 [밸런스 수치](specs/balance.md#확률과-알)를 따른다. |
