### 조사 결과

관측일은 2026-09-26이다.

- 어나더 레드는 Pokémon Essentials(RPG Maker XP)로 만들었다. 어나더 레드가 쓰는 한글 글꼴의 이름은 공개 자료에서 찾지 못했다. [나무위키](https://namu.wiki/w/%ED%8F%AC%EC%BC%93%EB%AA%AC%EC%8A%A4%ED%84%B0%20%EC%96%B4%EB%82%98%EB%8D%94%20%EB%A0%88%EB%93%9C)
- [Galmuri](https://github.com/quiple/galmuri)는 닌텐도 DS 글꼴을 참고한 도트 글꼴이다. 라이선스는 SIL OFL 1.1이다. 앱에 넣어 배포할 수 있다.
- Galmuri는 정해진 크기에서만 선명하다. Galmuri14는 15px, Galmuri11은 12px, Galmuri9는 10px, Galmuri7은 8px이다. 굵은 글꼴은 Galmuri11 Bold 하나다.
- 창틀 색은 PokéRogue 저장소의 3세대 창틀 그림 `images/ui/legacy/windows/window_1.png`~`window_3.png`에서 화소 값을 읽었다. 그림 파일은 쓰지 않는다. 색 값만 쓴다.

**강조 금지 규칙과의 관계** — 사용자 선호 규칙은 둥근 요소를 컬러 테두리로 강조하지 않는다. 창틀은 선택이나 상태를 강조하지 않는다. 창틀은 모든 컨테이너에 같은 모양으로 붙는 틀이다. 그래서 이 규칙의 예외로 기록한다. 선택 표현은 기존대로 왼쪽 막대와 옅은 배경이다.

### 구현 방법

- Figma: 외곽선은 1px 안쪽 테두리로 둔다. 밝은 테·틀·안쪽 선은 안쪽 그림자 3개로 둔다. 오프셋과 흐림은 0이고 퍼짐은 1·3·4px이다.
- CSS: `border: 1px solid` 외곽선과 `box-shadow: inset 0 0 0 1px …, inset 0 0 0 3px …, inset 0 0 0 4px …`로 같은 모양을 만든다.
- 제약: Figma 원격 도구(`use_figma`)는 Galmuri를 불러오지 못한다. 2026-09-26 `figma.loadFontAsync({ family: "Galmuri11" })`가 "font family does not exist"로 실패했다. 그래서 스타일 9개의 글꼴 이름은 사용자가 Figma 앱에서 바꾼다. 크기와 줄 높이는 도구로 먼저 바꾼다.

### 위험

- Galmuri 한글 글자는 Inter보다 넓다. 좁은 카드의 이름이 넘칠 수 있다. 예: 상점의 "가라두구머리장식".
- 스타일에 묶이지 않은 글자는 스타일을 바꿔도 따라오지 않는다.
- 캔버스 말풍선은 글꼴을 불러오기 전에 그리면 기본 글꼴로 나온다.
- 소수 배율 화면에서 도트 글꼴이 흐려질 수 있다.

### 수용 조건

1. Figma의 `PB/Type/*` 9개가 위 표의 값이다.
2. 창틀 대상 14개가 창틀 효과 스타일과 창틀 변수를 쓴다.
3. 화면 43개 캡처에서 글자가 잘리거나 넘치지 않는다.
4. 앱의 모든 창에서 글자가 Galmuri로 표시된다. 말풍선도 포함한다.
5. CSP 변경은 `font-src 'self'` 추가만이다.
6. `npm run selftest`, `node scripts/check-docs.cjs`, `git diff --check`를 통과한다.

### 재설계 — 기존 스타일 위의 Galmuri

날짜: 2026-09-26. 상태: 설계. 사용자 지시 원문: "다시 해야하는것들 꼼꼼하게 다 확인하고 전체 어떻게 할지 설계 좀 해봐. 진짜 내가해야해? 너가 못해? 이거 만든거는 다 만들어놓고 일일이 시키는게 이상한데?"

**지금까지 확정된 것** (사용자 발언 기준)
- 글꼴은 Galmuri다. Figma 스타일 9개는 사용자가 바꿨다.
- 3세대 창틀은 쓰지 않는다. BW 어두운 배경도 쓰지 않는다. 기존 밝은 스타일에 녹인다.
- 타입 배지는 기존 알약 모양이다. 여백을 줄였다.
- 파티 칸 시안(`473:15064`): 타입·수치 막대에 테두리가 없다. 선택 막대(blade)가 없다. 초상은 96px이다. 레벨과 이름은 한 줄이다. info는 작게 한다.

**열린 결정** `[스펙 미확정]`
1. 카드 외곽: 시안의 2px 깎은 모서리를 쓸지, 기존 1px 둥근 테두리로 둘지.
2. 선택 표시: 파티 칸에서 blade를 뺀 것이 파티 칸만인지, 모든 카드인지. 현재 공통 규칙은 blade다([UI 컴포넌트 계약](../../specs/ui-components.md#공통-규칙)).
3. 긴 글자: 말줄임과 두 줄 허용 중 무엇을 쓸지. 대상은 상점 설명, 가방 이름이다.
4. 선택 탭 앞의 ▶ 커서를 쓸지.
5. `09 · BW 스타일 시안` 페이지와 쓰지 않는 창틀 변수 15개·효과 스타일 `PB/Frame/Window`를 지울지.

**도구 제약과 해결** — Galmuri 글자 노드는 `use_figma`로 고칠 수 없다. 서버에 글꼴이 없기 때문이다. Chrome 연동으로 사용자 브라우저에서 고치는 방법은 2026-09-26 "Claude in Chrome is turned off in your settings"로 막혔다. 방법은 둘이다.
- A. 사용자가 Claude in Chrome을 켠다. 브라우저 안에서는 Galmuri를 불러올 수 있다. 그러면 글자 수정도 이 세션이 한다. 가능 여부는 켠 뒤 확인한다. `[스펙 미확정]`
- B. 글자를 고칠 때 이 세션이 스타일 9개를 Inter로 잠시 바꾼다. 모든 글자 수정을 한 번에 끝낸다. 마지막에 사용자가 스타일 9개를 Galmuri로 한 번 되돌린다. 넘침 검사는 Galmuri 상태에서 한다. 읽기는 글꼴 없이도 된다.
- 2026-09-27 갱신: A가 풀렸다. 지금 절차는 [Figma 글자 작업과 Galmuri 재배치](../../contributing/figma.md)를 따른다. B는 쓰지 않는다.

### Figma 반영

날짜: 2026-09-26. 도구: Figma 원격 도구 `use_figma`.

**변수와 스타일**
- `PB / Primitive`에 `window/*` 색 9개를 더했다. 값은 [창틀](#창틀) 표다.
- `PB / Color`에 `frame/outline`·`frame/fill`·`frame/highlight`·`frame/body`·`frame/inner`를 더했다. 모두 `window/*`의 별칭이다.
- `PB / Dimension`에 `radius/frame` = 4를 더했다.
