# S5 명칭과 기능 출처 검수

## 2026-09-21 — 요청 #119 삭제

### 작업

사용자의 전체 제거 지시에 따라 대상 상품의 기능과 명칭을 삭제했다. 과거 기록 보존 지침에도 이번 지시를 우선 적용했다.
`data/shop.json`(2026-09-27 삭제), 구매 처리(`src/shop/core.ts`, 2026-09-25 삭제), 메뉴(`src/main/game-menu.ts`, 2026-09-25 삭제), [명령 처리](../../../src/main/commands.ts)에서 관련 항목을 제거했다.
[저장 타입](../../../src/shared/types.ts)과 [정규화](../../../src/save/legacy.ts)에서 대상 필드를 제거했다.
진화 판단(`src/dex/progress.ts`, 2026-09-25 삭제)과 [해금 조건](../../../src/dex/unlocks.ts)에서 해당 제한을 제거했다.
한국어와 영어 문구를 삭제했다. 관련 검사를 정리했다. `dist/`는 빌드로 다시 생성했다.
현행 문서, 보관 문서, 과거 검수, 작성 예시에서 관련 언급을 제거했다.
사용자 저장 파일과 Git 이력은 직접 수정하지 않았다. 기존 재고와 로그의 임의 키를 일괄 삭제하는 처리는 추가하지 않았다.
이전 기록에서 이번 요청으로 삭제한 내용은 Git 이력에서 복구할 수 있다.

### 검수

| 명령 또는 방법 | 결과 |
|---|---|
| `npm run build` | 메인과 렌더러 빌드 통과 |
| `node dist/tools/selftest-save.js` | 저장 정규화, 이전, 파일, 잠금, mailbox 검사 통과 |
| `node dist/tools/selftest-dex.js` | 종, 친밀도, 시간대와 진화 대상 검사 통과 |
| `node dist/tools/selftest-state.js` | 육성, 돌봄, 숨김, 저장 실패 검사 통과 |
| `node dist/tools/selftest-shop.js` | 샌드박스에서 CLI snapshot 시간 초과. 승인 후 샌드박스 밖에서 동일 검사 통과 |
| `rg -n -i -uuu -g '!.git/**' <삭제 대상의 한글·영문 명칭 패턴> .` | 빌드 산출물과 숨김 파일을 포함한 검색 결과 0건. 종료 코드 1은 일치 없음이다. |
| `node scripts/check-docs.cjs` | 문서 구조, 파일 링크, JSON 검사 통과 |
| `git diff --check` | 공백 검사 통과 |

검색 패턴의 원문은 삭제 명칭을 다시 남기지 않기 위해 기록하지 않는다.
변경한 기술 문장을 수동으로 검수했다. 삭제로 끊긴 문장, 용어 일관성, 근거, 과거 결과와 이번 결과의 구분을 확인했다.
실제 Electron 화면 검사는 미실행이다. 메뉴 구성과 명령 처리는 상점 검사에서 확인했다.

### 피드백과 수정

문구 제거 후 보관 문서 두 곳에서 문장이 잘못 이어졌다. 원래 남길 문장의 의미에 맞게 수정했다.
상점 검사는 샌드박스 밖에서 통과했다. 검사 코드를 바꾸지 않았다.
요청 범위의 미해결 항목은 없다.
후속 사용자 요청에 따라 용어사전 정리와 요청 #119 변경을 함께 커밋한다. 푸시는 요청 범위에 없다.

## 2026-09-21 — 용어사전 후속 정리

### 작업

[후속 설계](plan.md#2026-09-21--용어사전-후속-정리-설계)에 따라 [용어사전](../../terms.md)을 개념별로 나눴다.
현재 구현, 기존 S5 설계, 미확정 제안, 제외 항목의 의미를 정의했다.
파티 칸, 빈 칸, 잠긴 칸, 미등록, 재소환을 추가했다. 육성과 보상 용어를 추가했다.
사용자 화면 용어와 내부 UI 자산 용어를 분리했다. 각 용어 묶음에 근거를 연결했다.
[S5 기능 계약](../../specs/s5.md)의 이로치 명칭 단정을 미확정 상태로 수정했다.
기존 상품 후보의 채택 상태는 유지했다. 앱 코드와 Figma는 변경하지 않았다.

### 검수

의미 검수 범위는 용어사전 전체와 이번에 변경한 기능 계약·현황·작업 기록·월별 이력의 문장이다.
한 문장 한 사실, 조건과 대상, 근거의 종류, 용어 일관성, 완료 범위, 원본 연결을 수동으로 확인했다.
명칭 정리를 사용자 승인이나 기능 구현 완료로 표현하지 않았는지 확인했다.
`node scripts/check-docs.cjs`를 통과했다. 문서 45개, 파일 링크 378개, JSON 5개를 확인했다.
`git diff --check`를 통과했다. 변경 문장의 의미 검수도 완료했다.
문서만 변경했으므로 빌드·린트·런타임 검사는 미실행이다.

### 피드백과 수정

기존 사전은 파티 전체를 칸으로 정의했다. 파티와 파티 칸을 분리했다.
기존 화면 설정 표에는 표 머리글이 없었다. 별도 절과 머리글을 추가했다. 최종 검수에서 표를 끊던 빈 줄도 제거했다.
기능 계약은 이로치를 확정 명칭으로 적었지만 사전은 미확정으로 적었다. 기능 계약을 사전의 상태에 맞췄다.
초안의 외국어 문자 오타 두 곳을 수정했다.
미확정 상품과 실행 환경 명칭은 이번 정리에서 채택하지 않았다. 해당 결정은 후속 작업으로 남는다.
이번 용어사전 정리 범위의 미해결 오류는 없다.

다른 모든 기능을 사용자가 거절했다고 해석하지 않는다. 추가 후보는 채택 근거가 확인되지 않았다는 뜻이다.
사용자의 구상과 필요한 기능을 정한 뒤 화면 명칭을 정한다. 원작의 상품명을 먼저 고르고 기능을 끼워 넣지 않는다.

- `git diff --check`를 통과했다.
- 코드 변경이 없으므로 빌드·린트·런타임 검사는 실행하지 않았다.
