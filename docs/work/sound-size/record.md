# 소리 크기와 그림 크기 단계

앱 소리를 줄이고 설정에 소리 크기를 둔다. 포켓몬 그림 크기 단계를 촘촘하게 바꾼다.
작업 절차는 [문서 작업 절차](../../contributing/workflow.md)를 따른다.

| 작업 | 상태 |
|---|---|
| 소리 처리(음량 규칙·알림음 교체) | 코드 완료. 시험 통과. 실제 소리 확인 미실행 |
| 설정 화면의 소리 크기 행 | 완료. Figma 컴포넌트·05 화면 반영. 캡처 확인 |
| 그림 크기 단계 | 코드 완료. 시험 통과. 캡처 확인 |

## 설계

날짜: 2026-09-27.

### 사용자 요청

원문: "시스템의 기본소리가 너무 커. 울음소리같은것들이 커서 좀 줄이고, 설정에 볼륨관련 추가하자. 1~5의 사이즈에서 각각의 갭이 너무 커. 지금 1과 2 중간의 사이즈가 있음 좋겠어. 지금3이 제일 큰거로. (추가적인 사이즈 키우는 요청이 있으면 바로 추가할 수 있게 구조 정리)"

### 관측

- 배너 알림음은 `shell.beep()`였다(`src/main/banner-window.ts`). OS 기본음이라 앱이 크기를 바꿀 수 없다.
- 울음소리 음량은 무대 0.2(`src/renderer/stage.ts`), 도감 기기 창 0.5(`src/renderer/dex.ts`)로 고정이었다.
- 그림 크기는 저장 값이 곧 정수 도트 배율 1~6이었다(`Pet.size`, `src/party/home.ts` `SIZE_RANGE`, 상세 단추 1~6).

### 결정과 제안

- 소리: 설정에 `volume`(0~100)을 둔다. 음량 = 설정 값 × 소리별 최대(`SOUND_RULES`). 기본값은 30이다. 울음소리 최대 0.5, 알림음 최대 0.35다. 기본에서 울음소리는 0.15다(옛 무대 0.2, 옛 기기 창 0.5). 제안 값이다.
- 2026-09-27 조정: 사용자 원문 "울음소리 기본소리 조금만 더 줄이자." 울음소리 최대를 0.35로 낮췄다. 기본 30에서 울음소리는 0.105다. 알림음은 그대로다.
- 알림음: 배너 창이 WebAudio로 짧은 두 음(988Hz → 1319Hz, 네모파)을 낸다. 파일을 넣지 않는다.
- 크기: 단계 번호와 배율을 표 하나(`SIZE_STEPS = [1, 1.5, 2, 2.5, 3]`)로 둔다. 저장은 배율을 적고, 화면·명령은 단계 번호를 쓴다. 저장이 배율이라 옛 저장의 1·2·3은 그대로다. 옛 4~6은 가장 큰 단계(3)로 줄인다. 더 큰 단계는 배열 끝에 배율을 더하면 단추 수까지 따라 늘어난다.
- 관측: 배율 1.5·2.5는 정수 배율이 아니라 도트 한 칸의 폭이 1~2px로 번갈아 나올 수 있다. 사용자가 반 단계를 요청했으므로 그대로 둔다.

### 기본 크기 (2026-09-27)

- 사용자 결정 원문: "기본크기 2로." 새 개체의 크기를 2단계(배율 1.5)로 한다. `DEFAULT_SIZE_LEVEL = 2`, `SAVE_V3_RULES.pet.size = 1.5`.
- 이미 있는 개체의 크기는 바꾸지 않는다. 사용자가 고른 값일 수 있어서다. 기존 개체도 바꾸려면 따로 정한다.
- 저장에 크기가 빠진 개체도 기본 단계로 읽는다.

### 수용 조건

1. 설정 `volume`은 0~100 정수만 받는다. 소리를 끄면 음량은 0이다.
2. 무대·도감 기기 창 울음소리와 배너 알림음이 설정 음량을 따른다.
3. 크기 단추가 1~5다. 단계 4는 배율 2.5, 단계 5는 3이다. 옛 저장의 4~6은 3이 된다.
4. 설정 화면의 행은 Figma 확인 뒤 구현한다.

## 작업

날짜: 2026-09-27.

**소리**
- `src/state/settings.ts`: 설정 키 `volume`, `SOUND_RULES`, `gainOf`.
- `src/shared/save-v3.ts`·`src/save/v3.ts`: `SettingsV3.volume`. 옛 저장은 기본값 30이다.
- `src/main/app.ts`·`stage-window.ts`·`preload.ts`·`src/renderer/stage.ts`: 무대 울음소리에 음량을 같이 보낸다(`stage:cry` = `{ uri, volume }`).
- `src/main/manage-window.ts`·`dex-window.ts`·`src/renderer/dex.ts`: 기기 창 `DexDeviceView.sound`를 `volume`으로 바꿨다. 0이면 울음소리 단추를 막는다.
- `src/main/banner-window.ts`·`src/renderer/banner.ts`: `shell.beep()`를 지우고 배너 창이 알림음을 낸다(`BannerView.chime`).
- `src/tx/snapshot.ts`: `SettingsView.volume`.

**크기**
- `src/save/rules.ts`: `SIZE_STEPS`, `sizeLevelOf`, `zoomOfLevel`, `snapSize`.
- `src/save/v3.ts`: 저장을 읽을 때 배율을 가까운 단계로 맞춘다.
- `src/party/home.ts`: `setSize`가 단계 번호를 받아 배율을 저장한다. `SIZE_RANGE`를 지웠다.
- `src/main/art.ts` `zoomOf`: 몸 상한 안의 가장 큰 단계 배율을 고른다.
- `src/tx/snapshot.ts`: `PetView.size`는 단계 번호다. `Snapshot.sizeLevels`로 단추 수를 준다.
- `src/renderer/manage.ts`: 크기 단추 수를 `sizeLevels`로 그린다.

**Figma 시안** — 페이지 `99 · 시안 (테스트)`, 섹션 `소리 크기 설정 시안 (2026-09-27)` `633:21597`. 교환 세션의 `Settings / General` 네 탭 화면을 복제했다.
- A `633:21598`: "알림 소리" 켬·끔을 소리 크기 슬라이더 하나로 합친다. 0이면 무음이다. 행 수가 그대로라 모달 500 안에 들어간다.
- B `633:21798`: 켬·끔을 두고 옆에 슬라이더를 더한다.
- 교환 세션 확인(2026-09-27): 네 탭 구조는 코드에 아직 없다. 행을 하나 더하면 `일반` 탭이 500을 2 넘는다. 그래서 두 안 모두 한 행 안에 넣었다.

**설정 화면 결정** (2026-09-27)
- 사용자 원문: "a로 하는데, 슬라이더 우측에 스피커 아이콘이 있고 누르면 음소거. 숫자는 입력가능하게 해. 사실상 b이긴한데, ui를 버튼으로. 슬라이더 우측에." 참고 그림은 스피커 아이콘과 가로 슬라이더다.
- 결정: 행 하나("소리")에 슬라이더 → 숫자 입력 → 스피커 단추 순서로 둔다. 스피커를 누르면 `settings.sound`를 끄고, 다시 누르면 켠다. 크기 값(`volume`)은 음소거해도 남는다. 음소거면 슬라이더·숫자를 흐리게 하고 단추에 옅은 배경을 둔다.
- 숫자 칸: 입력을 마치면(바깥 누름·Enter) 저장한다. 0~100 밖이나 소수는 0~100 정수로 맞춘다. 빈 칸이면 원래 값으로 되돌린다. 슬라이더는 놓을 때 저장한다.
- Figma: 01 Atoms `Icon / Sound` `645:346`(On·Muted), 02 Molecules `Volume Control` `645:16735`(On·Muted), 05 Screens `Settings / General` `633:18937`의 `setting/소리` `645:16736`. 설명은 "알림음과 울음소리 크기"다(코드에서 두 줄로 접혀 줄였다). 99 시안 섹션 `633:21597`은 지웠다. 교환 세션(terminal-pokemon-67)에 알렸다. 네 탭으로 옮길 때 이 행을 `일반` 탭에 둔다(그 세션 확인, 행 높이 43이라 500 안).
- 코드: `src/renderer/manage.ts` `volumeControl`·`speakerIcon`, `manage.html` `.volume`. `scripts/dev-manage.cjs`에 `--scroll <선택자>`를 더했다.

**Figma 정리** — 사용자 규칙 "시안에서 만들고 작업착수할 땐 실제화면으로 옮기고 시안은 정리"(Figma 세션 전달)에 따라, 99 페이지에서 이 세션의 섹션 두 개를 지웠다. `도감 기기 창 · 미해금 실루엣 시안` `579:17691`(05 Screens `Dex / Device`로 옮김)과 `화면 스타일 시안 (구 09)` `500:14437`(채택분은 `Party Slot Card`로 옮김, 나머지는 채택하지 않음)이다. 지우기 전에 섹션 밖에서 쓰는 컴포넌트가 없음을 확인했다.
