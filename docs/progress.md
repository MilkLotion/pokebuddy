1. 이 문서의 [작업 후보](#작업-후보)에서 진행 중인 항목을 확인한다.
2. `git status --short` 와 `git log --oneline -10` 으로 다른 세션의 미커밋 변경과 최근 커밋을 확인한다. 남의 미커밋 파일은 그 세션에 물은 뒤 손댄다.

## 다른 PC에서 재개

인계 기준일: 2026-09-27. 작업 브랜치는 `main`이다. 원격 저장소 이름은 2026-09-27 `pokebuddy` 로 바꿨다.

1. 작업 폴더의 변경을 먼저 확인한다. 로컬 변경이 없는 `main`에서 `git pull --ff-only origin main`으로 최신 설계 커밋을 받는다. 로컬 변경이나 분기 이력이 있으면 먼저 보존·동기화한다.
2. `git status --short`와 `git log -3 --oneline`으로 상태를 확인한다. Node.js `>=22.12` 에서 `npm install` 뒤 `npm run selftest` 로 확인한다.
3. 위의 다른 세션 재개 절차를 따른다. 앱 실행 환경이 필요하면 [기존 실행 흐름 재개 절차](work/runtime-e2e/record.md#다른-pc의-재개-절차)를 별도로 읽는다. 해당 기록은 당시 실행 흐름의 근거다.
4. 동기화 후 `node scripts/check-docs.cjs`와 `git diff --check`를 실행한다. 과거 검수 결과를 새 PC의 실행 결과로 사용하지 않는다.

현재 앱은 S5 새 게임 규칙을 저장 v3 로 돌린다. 2026-09-24 에 실제 앱을 v3 로 전환했다. Figma 작업 완료 여부와 앱 구현 완료 여부를 구분한다.

## 남은 플랫폼 확인

- Windows 배율과 마우스 입력을 확인한다.
- 여섯 마리의 CPU·GPU 사용량을 측정한다.
- macOS와 다중 화면 동작을 확인한다.

- PMD 특수 폼 매핑을 확인한다.
