# 임시 작업 기록

이 폴더는 임시 보관소다. `worklog/` 가 없는 컴퓨터(2026-09-28 Mac)에서 한 작업의 기록을 옮기려고 둔다.

`worklog/` 가 있는 컴퓨터에서 다음 순서로 정리한다.

1. `records/` 아래 폴더를 `worklog/records/` 로 옮긴다. 같은 작업 폴더가 이미 있으면 그 기록에 내용을 합친다.
2. `history-2026-09.md` 의 항목을 `worklog/history/2026-09.md` 에 붙인다.
3. `progress.md` 의 내용을 `worklog/progress.md` 에 반영한다.
4. 이 폴더를 지우고 `scripts/check-docs.cjs` 의 `allowedRootDirectories` 에서 `worklog` 를 뺀다.
