# 기술과 특성

이 문서는 포켓몬 기술·특성 데이터와 전투 규칙의 계약이다.

## 범위와 상태

- 배틀 엔진(`src/battle/engine.ts`)이 이 데이터와 [전투 규칙](#전투-규칙)을 쓴다(2026-10-08). 특성은 게으름·슬로스타트·스킬링크·모습이 바뀌는 5종·돌머리만 넣었다. 나머지 특성은 아직 무보정이다.
- 배틀 파티 상세 기기 창이 기술을 보인다. 특성은 보이지 않는다.
- 전투는 6 대 6 파티 오토배틀이다. 기술마다 쿨타임이 있다. 기술은 1번 → 2번 → 1번 → 2번 순서로 번갈아 자동으로 쓴다. 차례가 온 기술의 쿨타임이 차면 쓴다. 수동 사용은 지금 없다. 평타는 기술과 따로 나간다. 순서 규칙은 [배틀 방식](adventure.md#배틀-방식-설계-구현-전)에 있다.
- 데이터 값은 손으로 고친다. 밸런스 패치는 데이터 파일을 고친다.

## 데이터 파일

| 파일 | 내용 |
|---|---|
| [`data/moves.json`](../../data/moves.json) | 기술 표. 종 기술이 쓰는 기술만 있다 |
| [`data/species-moves.json`](../../data/species-moves.json) | 종마다 기본 기술 2개와 특수 종 표시 |
| [`data/abilities.json`](../../data/abilities.json) | 특성 표. 이름, 분류, 적용 시점, 오토배틀 적용안 |
| [`data/species-abilities.json`](../../data/species-abilities.json) | 종마다 특성 하나 |
| [`data/move-text.ko.json`](../../data/move-text.ko.json) | 기술 설명(한국어). 키는 `moves.json` 의 기술 id 다 |
| [`data/type-chart.json`](../../data/type-chart.json) | 타입 상성표. 공격 타입 → 방어 타입 → 배율(0·0.5·1·2), 18타입 |
| [`data/mega-battle.json`](../../data/mega-battle.json) | 메가·원시회귀 모습의 종족값 6개(`stats`)와 특성(`ability`). 키는 `data/mega.json` 의 모습이다 |
| [`data/species.defaults.json`](../../data/species.defaults.json) `stats` | 종족값 6개. 순서는 HP·공격·방어·특수공격·특수방어·스피드다 |
| [`data/form-battle.json`](../../data/form-battle.json) | 전투 중 모습이 바뀌는 5종의 다른 모습 종족값. 킬가르도(블레이드폼)·약어리(무리의 모습)·메테노(코어의 모습)·돌핀맨(마이티폼)·테라파고스(테라스탈폼). PokeAPI CSV 에서 만든다(`build-form-battle`) |

`moves.json` 기술 필드:

| 필드 | 뜻 |
|---|---|
| `ko`·`en` | 기술 이름 |
| `type` | 타입 |
| `class` | `physical`(물리)·`special`(특수)·`status`(변화) |
| `power` | 한 타 위력 |
| `hits` | 연속기의 `[최소, 최대]` 타수 |
| `accuracy` | 명중률. `null` 이면 반드시 맞는다 |
| `priority` | 원작 선공도. 공격기에만 적는다 |
| `cooldown` | 쿨타임(초) |
| `traits` | 성질. `contact`(접촉)·`bite`(물기)·`punch`(펀치)·`sound`(소리)·`pulse`(파동)·`ballistic`(탄환)·`slicing`(베기) |
| `effects` | 부담과 효과. `charge`(충전)·`recharge`(반동으로 쉼)·`recoil`(반동 피해 %)·`halfHp`(자기 HP 절반)·`drain`(흡수 %)·`selfDrop`(자기 능력 하락 단계)·`rampage`(난동)·`hpScale`(HP 비례 위력) |

`move-text.ko.json`·`type-chart.json`·`mega-battle.json`·`stats` 는 PokeAPI CSV 에서 만든다(`npm run data:build`). 손으로 고치지 않는다.

- 기술 설명은 한국어 문장이 있는 가장 최근 버전 그룹의 문장이다. 줄바꿈은 빈칸으로 바꾼다.
- 한국어 문장이 없는 기술은 키가 없다. 9세대·레전드 아르세우스 기술이 여기에 든다.
- 리전폼과 특수 폼은 종이라 폼의 종족값을 쓴다. 메가진화 모습은 종이 아니라서 종 표에 `stats` 가 없다.
- 메가진화 모습의 종족값과 특성은 `mega-battle.json` 에 있다. 메가 개체는 배틀·탐험에서 이 값으로 싸운다(2026-10-08 사용자 결정).
- PokeAPI 에 특성이 없는 메가 모습은 기본 종의 특성을 쓰고 `baseAbility` 를 적는다. 메가다크라이, 메가지가르데, 메가제라오라, 메가싸리용이다(2026-10-08 사용자 결정).

`species-moves.json` 칸이 문자열이면 기술 id 다. 칸이 객체면 기술 기본값을 덮는다. 변화기 전용기는 `class`·`power`·`cooldown` 을 덮는다. 모습에 따라 타입이 바뀌는 전용기는 `type` 을 덮는다. 예: 아르세우스(불꽃)의 심판의뭉치.

## 기본 기술 배치

### 칸

- 종마다 기술 2개다.
- 단일 타입 종은 그 타입 기술 2개다.
- 두 타입 종은 타입마다 1개다.
- 종 타입과 다른 전용기는 한 칸을 쓴다. 예: 타타륜(고스트·풀)의 앵커샷(강철).
- 사용자는 기술을 고르지 않는다. 진화하면 새 종의 기술이 된다.
- 메가진화와 모습 바꾸기는 기술을 바꾸지 않는다. 리전폼과 특수 폼은 다른 종이라 자기 기술이 있다.

### 처음 값을 정한 순서

데이터의 처음 값은 아래 순서로 정했다. 데이터를 고칠 때 같은 기준을 쓴다.

1. 전용기를 넣는다. 전용기는 한 진화 계열만 배우는 기술이다. 한 종에 하나만 넣는다.
2. 대표기술을 넣는다. 대표기술은 손으로 고른 기술이다. 예: 루카리오 파동탄, 핫삼 불릿펀치.
3. 남은 칸은 원작 대전의 기술 사용률 순으로 고른다.
4. 사용률 자료가 없으면 결정력 × 부담 계수 순으로 고른다.

전용기가 여럿이면 공격 전용기를 변화기 전용기보다 먼저 고른다. 그다음은 결정력 × 부담 계수 순이다.

### 위력 상한

자동으로 고르는 기술은 종의 위력 상한을 넘지 않는다. 전용기와 대표기술은 상한을 따르지 않는다.

| 종족값 합계 | 위력 상한 |
|---|---|
| 350 이하 | 65 |
| 351~479 | 85 |
| 480~599 | 120 |
| 600 이상 | 없음 |

- 공격·특수공격 중 높은 종족값이 120 이상이면 한 단계 올린다.
- 공격·특수공격 중 높은 종족값이 55 이하면 한 단계 내린다.
- 진화한 종의 상한은 진화 전 종보다 낮지 않다.
- 연속기는 기대 위력으로 상한을 본다.

### 결정력

결정력 = 실수치 × 위력 × 자속 보정 × 특성 보정이다.

- 실수치는 50레벨, 개체값 31, 노력치 252, 성격 보정 없음으로 계산한다.
- 물리 기술은 공격, 특수 기술은 특수공격을 쓴다.
- 자속 보정은 기술 타입이 종 타입과 같으면 1.5 다.
- 특성 보정은 종 특성 하나로 계산한다. 예: 어래곤 옹골찬턱은 물기 기술 ×1.5.
- 도구 보정은 없다.
- 전투 중 모습이 바뀌는 특성의 종은 가장 강한 모습의 능력치로 계산한다. 위력 상한도 그 모습의 종족값으로 정한다. 대상은 약어리(무리의 모습), 메테노(코어의 모습), 킬가르도(블레이드폼), 돌핀맨(마이티폼), 테라파고스(테라스탈폼)다.

### 부담 계수

자동으로 고를 때 결정력에 곱한다. 값은 원작 사용률과 견주어 정했다.

| 부담 | 계수 |
|---|---|
| 명중 | (명중률 / 100)^1.5 |
| 충전 | ×0.5 |
| 반동으로 쉼 | ×0.5 |
| 반동 피해 | ×(1 − 반동 비율) |
| 자기 HP 절반 | ×0.5 |
| 자기 능력 하락 | 단계마다 ×0.9 |
| 난동 | ×0.6 |
| HP 비례 위력 | ×0.6 |
| 선공 | ×(1 + 0.15 × 선공도), 선공도는 2까지 |

### 고르지 않는 기술

- 쓰면 기절하는 기술(대폭발·자폭 등).
- 특수 조건이 있어야 맞는 기술. 꿈먹기·코골기(잠듦), 속이다·만나자마자(첫 턴), 기습·기선제압(상대 행동), 비장의무기, 트림, 아이언롤러, 싱크로노이즈, 트랩셸.
- 잠재파워(8세대에서 빠짐).
- 폴터가이스트는 상대가 늘 도구를 가졌다고 보고 고른다.
- 질풍신뢰는 조건을 없애고 선공기로 쓴다.
- 이 게임에 없는 효과 때문에 쓰는 기술은 사용률을 믿지 않는다. 선공기, 교체기(유턴·볼트체인지·퀵턴·따라가때리기), 도구 기술(탁쳐서떨구기·도둑질·탐내다), 고속스핀·킬러스핀, 볼부비부비가 해당한다. 이 기술들은 결정력 × 부담 계수로만 겨룬다.

### 특수 종

| `special` | 종 | 규칙 |
|---|---|---|
| `transform` | 메타몽 | 전투가 시작되면 상대 파티의 같은 칸 포켓몬으로 변신한다. HP 를 뺀 능력치와 기술 2개를 따라 한다. 상대가 대장 포켓몬이거나 그 칸이 비면 기능 정지다 |
| `reflect` | 마자용·마자 | 카운터(물리)와 미러코트(특수). 쓰면 3초 동안 그 분류의 기술 하나를 받은 피해의 2배로 반사한다. 쿨타임 16초. 평타는 반사하지 않는다 |
| `sketch` | 루브도 | 전투가 시작되면 상대 파티의 기술 칸(6마리 × 2 = 12칸)에서 하나를 뽑고, 남은 11칸에서 하나를 더 뽑는다. 같은 기술이어도 쓴다 |
| `wall` | 병풍 38종 | 기술이 없다. 평타는 한다. 안농 28종, 캐터피·단데기·딱충이·개무소·실쿤·카스쿤, 잉어킹, 해무기, 코스모그·코스모움 |
| `stance` | 킬가르도 | 킹실드와 섀도볼. 아래 [킬가르도](#킬가르도) |

## 전투 규칙

탐험·배틀을 만들 때 적용한다. 값은 [스펙 미확정]이다. 써 본 뒤 고친다.

### 쿨타임

| 기대 위력 | 쿨타임 |
|---|---|
| 60 이하 | 4초 |
| 61~90 | 6초 |
| 91~120 | 8초 |
| 121 이상 | 10초 |

- 기대 위력은 한 타 위력 × 기대 타수다.
- 선공기는 구간으로 올리지 않는다. 쿨타임은 위력 ÷ 15초다. 원래 쿨타임의 절반보다 짧지 않다. 예: 전광석화 2.67초, 신속 5.33초.

### 전장과 대상

2026-10-08 사용자 결정이다. 엔진 구조는 [배틀 엔진](adventure.md#배틀-엔진-설계-구현-전)에 있다.

- 두 파티의 6칸이 전투 시작부터 한꺼번에 싸운다. 교대는 없다. 포켓몬은 걸어 나가 싸운다(오토체스).
- 전장은 화면 칸 가로 8 × 세로 5 다. 각 쪽 2열, 가운데 4열이다. 위아래에 빈 줄이 하나씩 있다.
- 계산은 화면 칸 하나를 2×2 로 나눈 정수 좌표(16 × 10)로 한다. 포켓몬 한 마리는 계산 칸 2×2(화면 칸 하나)를 차지한다. 포켓몬끼리·장애물과 겹치지 않는다.
- 처음 자리는 각 쪽 `1 2 / 3 4 / 5 6` 이고 가운데 3줄에 선다. 상대는 거울이다. 양쪽 모두 2·4·6번이 가운데 쪽 앞 열이다.
- 장애물: 판마다 시드로 계산 칸 1×1 두 개와 2×2 한 개를 뽑는다(2026-10-08 사용자 "장애물 1*1 2개, 2*2 1개로 줄이고"). 가운데 4열 안에 완전히 무작위로 놓는다. 움직임만 막고 부서지지 않는다. 양쪽이 서로 닿을 길이 없으면 다시 뽑는다.
- 이동: 모든 포켓몬이 같은 속도로 8방향을 걷는다. 계산 칸 1칸에 0.3초다. 대각선도 같다.
- 사거리: 포켓몬마다 하나이고 평타와 기술이 같이 쓴다. 두 몸 사이 틈(대각선 포함)이 사거리 이하면 때린다(2026-10-08 사용자 "사거리 너가 얘기한대로 해보자").
  - 종족값 특수공격이 공격보다 높으면 원거리다. 사거리는 계산 칸 6(화면 칸 3)이다. 같으면 근접이다. 메가 모습은 메가 종족값으로 본다.
  - 그 밖은 근접이다. 사거리는 계산 칸 1 이다.
  - 원거리는 대상이 사거리에 들어오면 멈춰서 쓴다. 근접은 붙을 때까지 걷는다.
  - 까닭: 모두 사거리 1 이면 앞 열끼리 가운데에서 벽처럼 부딪쳐 싸움이 정직해 보였다(사용자 "좀 퍼지면서 싸워지는걸 기대했는데 너무 정직하네").
  - 메타몽은 따라 한 상대의 사거리를 쓴다.
  - 원거리가 근접에게 붙잡혔을 때 물러나는지는 [스펙 미확정]이다. 지금은 물러나지 않는다.
- 대상: 장애물을 돌아가는 걸음 수로 가장 가까운 상대다. 같으면 같은 줄(위아래 차이가 작은 쪽), 그다음 번호가 작은 상대다. 대상은 쓰러질 때까지 바꾸지 않는다. 길이 막혀 닿을 수 없으면 다른 상대를 고른다.
- 사거리 밖이면 대상 쪽으로 걷는다. 다른 포켓몬이 길을 막으면 돌아가고, 돌아갈 길도 없으면 기다린다.
- 쿨타임은 판 시작부터 늘 돈다. 차례 기술(평타도)이 찼는데 대상이 사거리 밖이면 기다렸다가 사거리에 들어오는 순간 쓴다. 기술이나 평타를 쓰는 틱에는 걷지 않는다.
- 연속기의 남은 타는 대상이 쓰러지면 사거리 안의 가장 가까운 상대에게 간다. 사거리 안에 없으면 남은 타는 없다.
- 빈 칸은 처음부터 쓰러진 것으로 본다.
- 2026-10-08 사용자 결정이다(전장 크기·좌표·장애물·이동 속도·대상·쿨타임·몸 크기·사거리).

### 평타

- 평타는 기술과 따로 나간다. 평타 시계와 기술 시계는 따로 돈다.
- 평타 간격은 실제 스피드로 정한다. 스피드가 빠르면 평타를 더 자주 한다(2026-10-08 사용자 결정 "스피드빠르면 많이 때리게").
- 평타 간격 = 3초 × 100 ÷ (실제 스피드 + 50). 0.1초 단위로 올린다. 예: 스피드 25 는 4초, 50 은 3초, 100 은 2초, 200 은 1.2초. 값은 [스펙 미확정]이다. 모의 대전으로 맞춘다.
- 스피드의 능력 변화는 다음 평타 간격부터 적용한다.
- 스피드를 기술 쿨타임에도 쓸지는 [스펙 미확정]이다. 모의 대전 결과를 보고 정한다.

### 시간과 순서

- 전투 시계는 0.1초(100ms) 틱이다. 모든 시간은 틱의 정수배다. 쿨타임과 지속 시간은 틱 단위로 올린다.
- 전투가 시작되면 1번 기술의 쿨타임과 첫 평타 간격이 돈다.
- 기술을 쓰면 다음 차례 기술의 쿨타임이 돈다([기술 사용 순서](adventure.md#기술-사용-순서)).
- 한 틱에 행동이 여럿이면 다음 순서로 한다. 행동하지 않은 포켓몬은 그 뒤에 걷는다. 걷는 순서는 시드 난수로 섞는다.
  1. 기술이 평타보다 먼저다.
  2. 선공도가 높은 기술이 먼저다.
  3. 실제 스피드(능력 변화 포함)가 빠른 쪽이 먼저다.
  4. 그래도 같으면 시드 난수로 정한다.
- 앞 행동으로 쓰러진 포켓몬은 그 틱의 남은 행동을 하지 않는다.

### 판의 끝

- 한쪽 6칸이 모두 쓰러지면 다른 쪽이 이긴다.
- 같은 틱에 양쪽이 모두 쓰러지면 무승부다.
- 판 길이 상한은 90초다(2026-10-08 사용자 결정). 90초가 되면 남은 HP 비율의 합이 큰 쪽이 이긴다. 칸마다 현재 HP ÷ 최대 HP 를 1000 분율 정수로 내림해 더한다. 합이 같으면 무승부다.
- 무승부는 양쪽 모두 진 판으로 보상한다([배틀 보상](balance.md#배틀-보상)).

### 엔진에서 정한 세부

엔진을 만들며 정한 값이다. 모두 [스펙 미확정]이다. 모의 대전과 사용자 확인으로 고친다.

- 능력 변화의 배율·단계·지속은 [능력 변화](#능력-변화)를 따른다. 공격기의 능력 변화(`effects.stats`)는 기술이 한 번이라도 피해를 준 뒤에 건다. 빗나가거나 막히면 걸지 않는다. 자기 하락도 같다.
- 위협은 판이 시작될 때 건다. 플라워베일은 상대가 건 하락만 막는다. 자기 하락은 막지 않는다.
- 프레셔는 상대 쪽에 살아 있는 프레셔 포켓몬이 하나라도 있으면 건다. 여럿이어도 +10% 한 번이다.
- 아군 특성(프렌드가드·배터리·파워스폿 등)은 자기 쪽 살아 있는 아군 전체에 건다. 같은 특성이 여럿이면 곱한다. 원작에서 자신을 빼는 특성(프렌드가드·배터리·파워스폿)은 자신에게 걸지 않는다.
- 대접(판 시작 HP 회복)과 협연(능력 변화 복사)은 판 시작에 HP 가 가득하고 능력 변화가 없어 효과가 없다.
- 명중은 기술을 쓸 때 한 번 본다. 빗나가면 연속기의 모든 타가 빗나간다.
- 스킬링크 기술은 쿨타임 대신 스택으로 준비된다. 차례가 오면 3스택 이상일 때 그때의 스택 수만큼 때린다.
- 킬가르도는 첫 기술을 쿨타임(6초) 뒤에 쓰고, 그 뒤 3초마다 두 기술을 번갈아 쓴다.
- 킹실드에 막히면 그 기술의 남은 타도 나가지 않는다.
- 마자용의 반사는 한 번 쓰면 3초 안에 처음 받은 같은 분류의 기술 한 번에만 걸린다. 마자용도 그 피해를 받는다.
- 메타몽은 HP 를 뺀 능력치·타입·기술을 따라 한다. 같은 칸이 비거나 메타몽이면 기능 정지다. 기능 정지는 기술 없이 평타만 한다.
- 루브도가 뽑은 변화기(킹실드 등)는 그 효과만 낸다. 반사 기술(카운터·미러코트)은 아무 효과가 없다.
- 약어리는 개체가 Lv.60 이상이면 무리의 모습으로 시작한다. 배틀의 50레벨 계산과 상관없이 개체의 실제 레벨로 본다.

### 피해

- 피해는 결정력 공식처럼 스탯에 비례한다.
- 공식은 원작 50레벨 공식을 따른다. 값은 [스펙 미확정]이다. 모의 대전으로 맞춘다.
  - 기본 피해 = ⌊⌊22 × 위력 × 공격 ÷ 방어⌋ ÷ 50⌋ + 2
  - 물리 기술은 공격·방어, 특수 기술은 특수공격·특수방어를 쓴다. 능력 변화를 곱한 값이다.
  - 피해 = ⌊기본 피해 × 자속 × 상성 × 특성 보정 × 난수⌋. 난수는 85~100 의 정수 ÷ 100 이다.
  - 상성이 0 이 아니면 피해는 1 이상이다. 급소는 없다.
- 탐험은 개체의 실제 레벨을 쓴다. 공식의 22 는 ⌊2 × 레벨 ÷ 5⌋ + 2 다.
- 전투 HP 는 실제 HP × 3 이다(2026-10-08 사용자 결정 "일단 3배로 해서 게임돌려보고 하자"). 판 길이를 늘려 1번·2번 기술을 여러 바퀴 쓰게 하려고다. 기기 창은 실제 HP 를 그대로 보인다. 비율로 정한 규칙(HP 비례 위력, 모습 바뀌는 HP 조건, 90초 판정, 자기 HP 절반)은 전투 HP 로 계산한다. 배율은 모의 대전으로 다시 본다.
- 상성은 원작 18타입 상성표를 쓴다. 두 타입이면 곱한다. 효과 없음(×0)도 원작대로다.
- 명중률만큼 맞는다. 빗나가면 "빗나감!" 을 띄운다.
- 기술은 조건 때문에 실패하지 않는다.
- 평타는 위력 20이다. 상성과 자속을 타지 않는다. 공격·특수공격 중 높은 쪽을 쓴다. 방어는 고른 쪽에 맞는 방어·특수방어다. 평타는 반드시 맞는다.

### 연속기

- 2~5회 기술은 쓸 때마다 타수를 뽑는다. 2회 35%, 3회 35%, 4회 15%, 5회 15%다.
- 찍찍베기(1~10회)는 한 타마다 90% 로 다음 타가 이어진다.
- 피해는 타마다 따로 계산하고 따로 보인다.
- 상대가 도중에 쓰러지면 남은 타는 가장 가까운 상대 포켓몬에게 간다.
- 스킬링크 종의 2~5회 기술은 스택형이다. 스택 1개 = 1타, 최대 5스택이다. 스택 하나의 충전 시간은 기술 쿨타임 ÷ 5다. 3스택에서 쓴다. 수동 사용이 생기면 1스택부터 언제든 쓰게 한다.

### 부담과 효과

| 효과 | 규칙 |
|---|---|
| 충전 | 쿨타임이 처음 차면 충전한다. 다시 차면 나간다. 날씨가 생기면 쾌청의 솔라빔처럼 바로 나가는 조건을 둔다 |
| 반동으로 쉼 | 쓴 뒤 다음 기술의 쿨타임이 2배다 |
| 반동 피해 | 준 피해의 `recoil`% 를 자신이 받는다 |
| 자기 HP 절반 | 자기 최대 HP 의 50% 를 잃는다 |
| 흡수 | 준 피해의 `drain`% 를 회복한다 |
| 자기 능력 하락 | 쓴 뒤 시간제 능력 하락이 걸린다 |
| 난동 | 쓴 뒤 2초 동안 행동하지 못한다 |
| HP 비례 위력 | 위력 × 현재 HP 비율 |

### 능력 변화

- 원작 랭크 대신 시간제 배율을 쓴다.
- 1단계 ×1.2, 2단계 ×1.4, 10초 지속이다.
- 같은 효과가 다시 걸리면 시간만 새로 시작한다.

### 특성

- 종마다 특성 하나다. 지금은 화면에 보이지 않는다.
- 처음 값은 원작 대전 사용률 1위 특성이다. 1위가 효과 없는 특성(`when` 이 `none`)이거나 변환자재·리베로면 다음 순위 중 효과 있는 특성이다. 효과 있는 후보가 없으면 1위를 그대로 둔다.
- 노가드 종은 기술을 고를 때 명중 계수를 쓰지 않는다. 돌머리 종은 반동 피해 계수를 쓰지 않는다. 그 밖의 특성은 기술 고르기의 부담 계수를 바꾸지 않는다.
- `abilities.json` 의 `when` 이 적용 시점이다. `now` 는 전투에 바로 적용한다. `later` 는 날씨·필드·상태 이상·교체·명중 외 시스템이 생기면 적용한다. `none` 은 효과가 없다.
- 게으름(게을로·게을킹): 첫 쿨타임은 보통이다. 한 번 쓴 뒤로 기술과 평타의 쿨타임이 2배다.
- 슬로스타트(레지기가스): 첫 기술과 첫 평타까지의 쿨타임이 5배다.
- 날씨 특성은 보류한다. 기술 고르기에 넣지 않는다.
- 메가 모습의 특성 7개는 2026-10-08 에 더했다(사용자 결정). 부자유친·스카이스킨·Eelevate 는 `now` 다. 시작의바다·끝의대지·델타스트림은 날씨라 `later` 다. 관통드릴은 방어 기술이 없어 `none` 이다. Eelevate 는 PokeAPI 에 한국어 이름이 없어 영어 이름을 쓴다.

### 모습이 바뀌는 종

| 종 | 특성 | 규칙 |
|---|---|---|
| 약어리 | 어군 | 어군 모습 바꾸기는 60레벨에 해금된다. 해금 뒤에는 무리의 모습으로 시작하고, HP 25% 미만이면 단독의 모습이 된다. 해금 전에는 단독의 모습으로 싸운다. 기술은 해금과 상관없이 무리의 모습 기준이다. 단독의 모습은 종족값이 낮아 피해가 작다 |
| 메테노 | 리밋실드 | 유성의 모습(방어형)으로 시작한다. HP 50% 이하면 코어의 모습(공격형)이 된다 |
| 돌핀맨 | 마이티체인지 | 나이브폼으로 시작한다. 두 기술을 한 번씩 쓴다. 먼저 쓴 기술의 쿨타임이 다시 차면, 그 기술을 쓰기 전에 마이티폼으로 변신한다. 그다음 그 기술을 쓴다 |
| 테라파고스 | 테라체인지 | 전투 시작부터 테라스탈폼이다 |
| 킬가르도 | 배틀스위치 | 아래 [킬가르도](#킬가르도) |

받는 피해와 능력치는 그때의 모습으로 계산한다.

### 킬가르도

- 기술은 킹실드와 섀도볼이다. 둘 다 쿨타임 6초다. 시작을 3초 어긋나게 한다.
- 섀도볼을 쓰면 블레이드폼, 킹실드를 쓰면 실드폼이 된다. 폼은 3초마다 바뀐다.
- 킹실드는 쓴 뒤 2초 동안 받는 기술을 막는다. 막은 공격이 접촉이면 상대 공격이 1단계 내려간다. 평타는 막지 않는다.
- 결정력은 블레이드폼 능력치로 계산한다. 받는 피해는 그때의 폼으로 계산한다.

## 보류 기능

- 기술 선택: 최종 진화 종이 기본 2개와 후보 4개를 갖고, 빈 기술머신으로 후보를 해금해 고르는 방식이다. 보류했다. 지금은 기본 2개만 쓴다.
- 종 타입과 다른 기술(견제기)은 후보에 넣지 않는다.

## 검사

- `node dist/tools/check/check-moves.js` 가 데이터 짜임새를 본다. `npm run selftest` 에 들어 있다.
- 검사는 칸 수, 칸 타입, 기술·특성 id, 이름, 위력, 쿨타임을 본다.
- 검사는 종족값 6개(합이 `bst`), 기술 설명 키, 상성표 18 × 18 과 배율 값도 본다.
- 검사는 `mega-battle.json` 의 키가 `mega.json` 의 모습과 같은지, 종족값 6개와 특성 id 도 본다.
- 검사는 종 타입과 다른 칸이 전용기인지 판단하지 않는다. 다른 칸은 하나까지만 허용한다.
