# UI 컴포넌트 계약

Figma 원본: [0.2 · 와이어프레임(구 07)](https://www.figma.com/design/MA3K41Y6omAi5mRu6YDFly/pokebuddy?node-id=252-121)의 WF-01~WF-09와 상태 예시, Figma `00`~`04` 자산.

## 읽는 기준

이 문서는 화면에서 반복되는 UI의 계약이다. 게임 규칙은 [현재 설계](../design.md)와 [S5 기능 계약](game.md)을 따른다. 흐름은 [사용자 시나리오](scenarios.md)를 따른다.
각 계약의 동작은 확정 규칙에서 가져왔다. 크기·배치·문구는 와이어프레임의 제안이며 `[스펙 미확정]`이다.
판정은 기존 Figma 자산 기준이다. `재사용`은 그대로 쓴다. `수정`은 기존 자산에 변형이나 속성을 더한다. `신규`는 새로 만든다.

## 공통 규칙

| 규칙 | 내용 |
|---|---|
| 선택 표현 | 카드·목록 항목은 옅은 배경만 쓴다. 왼쪽 세로 막대는 쓰지 않는다. 메인 탭은 옅은 배경과 밑줄이다. 필터 칩은 진한 채움과 흰 글자다. 두 칸 전환은 회색 틀 안의 흰 칸이다. 헤더 아이콘은 모달이 열린 동안 진한 배경이다. 규칙은 [현재 설계](../design.md#s5-디자인-시스템-v2)를 따른다. |
| 강조 금지 | 둥근 모서리 요소를 컬러 테두리나 왼쪽 컬러 선으로 강조하지 않는다. 경계용 1px 중립 테두리는 쓴다. |
| 높이 통일 | 같은 줄의 버튼·칩·입력칸은 같은 시각 높이다. 테두리가 없는 쪽은 안쪽 여백을 축당 1px 늘린다. 같은 줄의 카드는 같은 높이다. |
| 숨김 표시 | 숨긴 개체는 초상 우측 위의 닫힌 몬스터볼 마커로 표시한다. 글자 태그를 쓰지 않는다. 규칙은 [S5 기능 계약](game.md#1-목표와-결정)을 따른다. |
| 비활성 | 비활성 버튼은 회색 면과 흐린 글자다. 이유는 가까운 곳에 한 줄로 쓴다. |
| 처리 중 | 조작의 답이 0.3초 안에 오지 않으면 누른 버튼이나 칸만 처리 중으로 바꾼다. 버튼은 폭과 색을 그대로 두고 글자 자리에 점 세 개가 차례로 밝아진다. 칸은 내용을 옅게 덮고 초상 가운데에 점 세 개를 둔다. 답이 올 때까지 다른 조작은 받지 않는다. Figma: `Button` `113:313`·`Box Slot` `333:231` 의 `State=Busy`. |
| 글꼴 | 모든 글자는 Galmuri다. 크기는 24·15·12·10px 네 단계만 쓴다. 카드의 이름·설명이 칸보다 길면 한 줄로 두고 끝을 말줄임한다. |
| 빈 상태 | 빈 상태는 한 줄 문구만 둔다. 설명 문구를 덧붙이지 않는다. |
| 경고·안내 | 오류·주의·완료·안내는 `Alert` 로 보인다. 종류는 바탕 톤과 16px 픽셀 아이콘(`!`·`✓`·`i`)으로 구분한다. 테두리는 없고 모서리는 8px 이다. 내용 카드(흰 바탕, 중립 테두리, 12px)와 모양을 나눈다. 제목이 있으면 제목과 설명 두 줄(Banner)이다. 사용자가 닫는 배너에만 오른쪽 `✕` 를 둔다. `Alert` 는 그 상태가 이어지는 동안 늘 보이는 안내(저장 실패, 계정 분실·막힘, Node.js 없음)에만 쓴다. 누른 결과와 명령 실패는 새 줄을 끼웠다 빼지 않는다. 이미 있는 자리의 글자·색만 바꾼다(아래 `결과·실패 표시`). Figma: `Alert` `1040:279`(Tone=Error·Warning·Success·Info, Type=Banner·Inline). 구현: `src/renderer/manage.ts` `alertBox`, `manage.html` `.alert`. (2026-09-30 사용자 결정 "시안 괜찮네") |
| 결과·실패 표시 | 누른 결과와 명령 실패는 레이아웃을 바꾸지 않는다. 가방 사용·판매 판은 미리보기·요약 상자가 결과면 초록(`use-preview ok`), 실패면 빨강(`use-preview bad`)으로 바뀐다. 첫 줄은 결과나 `쓰지 못했어요`·`팔지 못했어요`, 둘째 줄은 쓴 수나 이유다. 도구를 다 써서 판이 닫히면 결과를 따로 두지 않는다. 구매 창은 합계 상자가 빨강 `사지 못했어요` 로 바뀐다(`buy-total bad`). 그 밖의 대화상자는 바닥 단추 줄의 빈자리(보조 단추와 주 단추 사이의 `spacer` 안, 없으면 줄 끝)에 빨간 점과 한 줄 글자를 둔다(`footer-error`, 길면 말줄임, 전체는 title). 단추 자리는 그대로다. 바닥 단추 줄이 없는 대화상자만 예전처럼 본문 끝에 `Alert` Inline 을 둔다. 연결 탭은 그 CLI 줄의 상태 글자와 점 색으로 보인다. Figma: 05 섹션 `결과·실패 표시`(R1·R2·R3), `Dialog` `299:3575` `error-notice`. 구현: `src/renderer/manage.ts` `bagPanel`·`drawDialog`, `manage.html` `.use-preview.ok`·`.bad`·`.footer-error`. (2026-09-30 사용자 결정 "레이아웃 왔다갔다하는건데? 나 이런거 싫어한다니까?") |
| 모달 | 업적창·설정·개체 선택·구매 창은 어두운 배경 위 대화상자다. 닫으면 보던 탭으로 돌아간다. |

## 계약

### C-01 앱 헤더

역할: 설정창 맨 위에서 브랜드, 보유 포인트, 업적창·설정·사용자 진입을 보여준다.
내용: 브랜드(앱 로고 20×20과 `PokeBuddy` 글자), 보유 포인트, C-02 업적 아이콘, C-02 설정 아이콘, C-02 유저 아이콘.
상태: 업적 미수령 있음·없음. 업적 모달 열림. 설정 모달 열림. 사용자 모달 열림.
브랜드의 로고는 `assets/logo/src/logo.svg` 를 인라인 SVG 로 넣는다. 창의 CSP 가 파일 그림을 막기 때문이다(2026-09-28 사용자 결정).
사용 화면: 설정창 모든 탭, WF-01~WF-05, WF-01b.
판정: `App Header`에 업적·설정 아이콘 자리를 더한다. 기존 설정 탭 진입은 아이콘으로 옮긴다.
Figma: `App Header` `154:1017`의 브랜드 `App Brand` `150:145`는 로고 `Brand Mark` 20×20과 `PokeBuddy` 글자다. 업적·설정·유저 버튼은 탭 줄 `Primary Navigation` `208:542`의 `header-icons`에 있다. 코드도 탭 줄(`nav`)에 둔다. 버튼은 노출한 인스턴스다. 인스턴스에서 dot와 열림 상태를 바꾼다. 상태 예시는 `295:3297`이다.
보유 포인트 왼쪽에 C-27 저장 표시(`save-indicator`)를 두었다. `Show Save Indicator` 속성(기본 꺼짐)으로 켠다. 로그인한 계정과 익명 계정에서 켠다. 상태는 노출한 `save-indicator` 인스턴스의 `State`로 고른다.

### C-02 헤더 아이콘 버튼

역할: 업적창, 설정 모달, 사용자 모달을 연다. 순서는 업적, 설정(톱니바퀴), 유저(사람 모양)다. 설정 아이콘은 슬라이더에서 톱니바퀴로 바꿨다(2026-09-28 사용자 요청).
상태: 기본, 모달 열림(진한 배경). 업적 아이콘은 미수령 보상이 있으면 우측 위에 dot를 표시한다. 모달 열림은 그 아이콘이 여는 모달(업적·설정·사용자·우편함)이 떠 있는 동안 `--primary` 바탕에 흰 아이콘이다(`src/renderer/manage.ts` `markHeaderOpen`, `manage.html` `.icon.open`, 2026-09-30 구현).
규칙: 미수령 dot는 업적 아이콘에만 쓴다. 부화·진화에는 쓰지 않는다.
Figma: `Header Icon Button` `295:3083`. 상태는 `Default`·`Hover`·`Open`·`Focus`다. 속성은 `Icon` 교체와 `Show Dot`이다. dot는 `Status Dot`의 `Danger`다. 아이콘은 `Icon / Achievement` `295:123`, 톱니바퀴 `Icon / Options` `202:144`, 사람 모양 `Icon / User` `821:742`다. `Open`은 아이콘 선을 흰색으로 덮어쓴다. 교체 아이콘의 벡터가 2개보다 많으면 흰색이 일부에만 적용된다. 대화상자의 닫기 버튼도 이 컴포넌트를 쓴다.

### C-03 메인 탭

역할: 파티 / 박스 / 도감 / 상점 / 가방 사이를 이동한다.
교환은 탭이 아니다. 박스 탭 머리 오른쪽의 `교환` 보조 단추(`돌보미집` 단추 옆)가 교환 모달을 연다(2026-09-30 사용자 결정 "교환 버튼을 만들고, 모달로 기존의 교환 창 띄우게."). 교환이 진행 중이면 단추 오른쪽 위에 dot 를 둔다(`Status Dot` 관례, 컬러 테두리 없음). 구현은 `src/renderer/manage.ts` `tradeOpenButton`·`syncTradeDot`, `manage.html` `.trade-open` 이다. Figma 04 템플릿 `Box Layout` `340:3665` 머리의 `actions`(돌보미집·교환). 옛 `Box / Trade Button` `1016:1891` 은 템플릿에 합쳐 지웠다(2026-09-30). 탭 줄 `Primary Navigation` `208:542` 의 모든 변형에 교환 탭이 없다.
상태: 탭별 선택(옅은 배경과 밑줄), 기본. 업적·설정·사용자 모달이 열려도 탭 선택은 그대로다.
판정: `Primary Navigation`의 `Active` 변형을 `Party|Box|Pokédex|Shop|Bag`로 바꾼다. `Settings`를 뺀다. 박스 아이콘이 새로 필요하다. 선택 밑줄은 내비게이션 `114:967`의 규칙을 따른다.
구현: 탭은 72×32 알약(반지름 10)에 16px 아이콘과 글자다. 아이콘과 글자는 탭 가운데에 둔다(좌우 여백이 같다. 두 글자면 12). 고른 탭은 옅은 배경, 굵은 글자, 가운데 60×2 밑줄(x 6, y 31.5)이다. `src/renderer/manage.ts` `TAB_ICON`·`drawTabs`, `manage.html` `nav .tabs` 다(2026-09-29 코드를 Figma 에 맞춤. 2026-09-30 좌우 정렬 수정, Figma `Navigation Item` `114:137`(`State=Selected` `114:129`)·탭 줄 `Primary Navigation` `208:542`, 사용자 요청 "실제메뉴에서는 좌우정렬 안맞음").
Figma: `Primary Navigation` `208:542`의 항목을 `파티·박스·도감·상점·가방` 순서로 바꿨다. `Active=Settings`는 인스턴스가 없어서 `Active=Box`로 바꿨다. `Icon / Box` `294:353`을 새로 만들었다.

### C-04 파티 칸 카드

역할: 파티 2열×3행의 한 칸을 보여준다.
상태: `포켓몬`, `포켓몬·숨김`, `빈 칸`, `잠긴 칸`. 잠긴 칸은 `잠긴 칸`만 보인다. 여는 경로(상점·업적)는 표시하지 않는다.
내용(포켓몬): 원형 초상과 숨김 마커, 머리 줄(레벨·이름·성별 아이콘), 타입 배지, C-05 친밀도·만복도를 한 줄에 나란히. 오른쪽 위에 상태 배지를 둔다. 순서는 디버프(배고픔 주황·매우 배고픔 빨강) 다음 켜진 버프(든든함·신남·들뜸, 초록 점)다. 성격은 2026-09-30 부터 보이지 않는다(Figma `Party Slot Card` 의 `nature` 레이어 숨김, `Traits` `Show Nature` 기본 꺼짐). 버프는 같은 날 타입 줄에서 상태 배지로 옮겼다(사용자 결정).
버프 배지는 이름 뒤에 남은 시간을 쓴다. 1시간 미만은 분이다(`신남 12분`). 1시간 이상은 올림한 시간이다(`든든함 2시간`). 0분은 `1분`으로 쓴다. 배지 한 줄 폭에 맞춘 짧은 꼴이다. 남은 시간은 1초 시계가 고친다(`src/renderer/manage.ts` `buffBadge`·`applyLive`, 2026-09-30 사용자 결정 "추천대로 진행해").
내용(빈 칸·잠긴 칸): 가운데 아이콘, 제목, 설명 한 줄. 빈 칸 설명은 `박스에서 배치`다.
규칙: 같은 줄 카드 높이를 맞춘다. 와이어프레임 크기는 330×160이다. 빈 칸을 누르면 파티 교체 모달이 열린다. 포켓몬 칸을 누르면 파티 상세 기기 창(C-28)이 열린다. 기기 창에 뜬 개체의 카드는 옅은 배경이다.
판정: `Pokemon Card`와 `Party Slot Card`를 하나의 상태 세트로 묶는다. 만복도를 더한다. 승인 UI의 `빈 슬롯`·`잠긴 파티칸`·`도감에서 소환` 문구를 용어사전 기준으로 바꾼다.
Figma: `Pokemon Card`를 `Party Slot Card` `194:317`의 `State=Pokemon`으로 옮겼다. 기존 인스턴스 6곳과 켜기·끄기 값은 유지됐다. 숨김은 별도 변형 대신 `Show Visibility Marker`로 켠다. 친밀도·만복도는 `Stat Meter` Narrow 두 개다. 빈 칸·잠긴 칸 문구는 `Party Slot` `151:158`에서 바꿨다. 카드 폭은 기존 320을 유지했다. 상태 예시는 `298:3408`이다.

### C-05 수치 막대

역할: 친밀도, 만복도, 경험치를 이름·수치·막대로 보여준다.

규칙: 채움 길이는 수치 비율이다. 예상 경험치처럼 현재와 다른 값은 시각 디자인 단계에서 구분 표현을 정한다.

판정: `Friendship`을 이름·수치를 바꿀 수 있는 공통 막대로 수정한다.
Figma: `Friendship`을 `Stat Meter` `296:190`의 `Size=Wide`로 바꾸고 `Size=Narrow`를 더했다. 이름·수치는 노출한 `label`·`value`로 바꾼다. Figma는 인스턴스 안 레이어의 크기를 바꿀 수 없다. 그래서 채움 길이는 `Stat Meter Bar` `298:155`의 `Fill` 변형에서 10% 단위로 고른다.

### C-06 박스 칸

역할: 30칸 박스의 한 칸을 보여준다.
상태: `개체`, `빈 칸`, `선택`.
내용: 원형 초상, 이름, 레벨. 숨긴 개체 표시는 없다. 박스 개체는 파티 밖이기 때문이다.
변형: 박스 탭용 기본 크기, 파티 교체 모달용 작은 크기(초상 28, 높이 66).

Figma: `Box Slot` `333:231`. `State=Pokemon|Empty|Selected|InParty|Busy`와 `Size=Default|Compact`의 10개 변형이다. `Busy`는 공통 규칙의 처리 중이다. `InParty`는 공유 개체 중 파티에 나가 있는 종이며 고를 수 없다. `Show Shared`는 같은 개체를 공유하는 두 칸의 표시다.

### C-07 박스 넘김 줄

역할: 박스를 넘긴다.
내용: `◀`, `박스 N`, `사용 칸 / 30`, `▶`, 오른쪽 끝 정렬. 이름 검색은 두지 않는다(2026-09-30 사용자 결정). 파티 교체 모달은 정렬도 두지 않는다.
규칙: 줄 안의 버튼 높이를 맞춘다. 박스가 모두 차면 새 박스가 생긴다.
검색 칸 공통 규칙(도감·상점 포켓몬 탭): 칸 옆에 `검색` 단추를 둔다. 단추 높이는 칸과 같다. 입력 중에는 결과를 바꾸지 않는다. Enter 나 `검색` 단추를 누를 때 그 값으로 한 번 거른다(2026-09-29 사용자 결정). 한글 조합 중에 Enter 를 누르면 검색을 예약한다. 조합이 확정된 직후 그 값으로 한 번 거른다. 그래서 Enter 는 한 번만 누른다. 조합 중에는 칸을 새로 만들지 않는다. 지우기(×)로 칸을 비우면 바로 전체로 돌린다. 검색 전에 입력한 글자는 다시 그려도 남는다. 검색 칸에 입력하는 동안에는 화면을 다시 그리지 않고 칸을 떠날 때 그린다. 칸을 새로 만들면 한글 조합이 끊기기 때문이다. 구현은 `src/renderer/manage.ts` `searchBox`, 검사는 `src/tools/smoke-manage.ts`이다.
사용 화면: 박스 탭, 파티 교체 모달(박스·파티 칸), 가방 사용 패널의 `박스`.
정렬: `정렬 ▾` 을 누르면 기준 목록(도감 번호·레벨 높은 순·친밀도 높은 순·최근 얻은 순·이름순)이 칸 아래에 뜬다. 고르면 지금 박스만 한 번 정렬한다. 바깥을 누르면 닫힌다.
박스 이름: 이름을 누르면 입력칸이 된다. Enter·바깥 클릭으로 저장하고 Esc 로 취소한다. 최대 10자다.
끌기: 개체 칸을 끌면 원래 자리는 흐려지고, 놓을 칸과 `◀`·`▶` 는 옅은 바탕(`bg/accent`)으로 보인다. 테두리로 강조하지 않는다. 새로 그리기: 설정창은 앱의 1초 시계마다 스냅샷을 다시 읽는다(2026-09-29 사용자 지시 "앱 자체의 전역으로 타이머 기능 만들고, 그게 1초마다 갱신"). 아래 방식은 구현 판단이다. 시간으로만 바뀌는 값(만복도·친밀도 막대, 알 남은 시간, 밥 주기 쿨타임 등)만 달라졌으면 그 표시만 고친다. 그래서 탭의 키보드 포커스, title 툴팁, 글자 선택이 남는다. 그 밖의 모양이 바뀌면 전체를 다시 그리고 포커스를 같은 자리의 요소로 되돌린다. 전체 다시 그리기는 끌기·박스 이름 입력·누르는 중(눌렀다 떼기 사이)·한글 조합 중·글자 입력 칸 포커스 동안 미룬다. 슬라이더는 누르는 중에만 미룬다. 표시 고치기는 미루는 동안에도 한다. 파티 상세 기기 창도 같은 방식이다.
목록 폭: 정렬 목록과 도감 지방 목록은 누르는 칸과 폭이 같다. 누르는 칸은 가장 긴 선택지가 들어가는 고정 폭이다. 정렬 124, 도감 지방 112다. 목록 글자는 앱 글꼴(Galmuri)을 쓴다.
Figma: `Box Toolbar` `337:284`. 버튼과 입력칸은 높이 32다. 정렬 칸은 124다. `Show Sort`로 정렬 칸을 끈다. 도감 지방 칸은 `Dex Layout` `378:1524` 의 `region`(112)이다. 열린 목록은 05 `Box / Sort Open` `633:17372`·`Dex / Region Open` `659:16723`. `검색` 단추는 `Box Toolbar` 의 `search-go` `967:27824`, `Dex Layout` 의 `search-go` `965:21148` 이다(2026-09-30).

### C-11 도감 종 카드

역할: 도감 목록의 한 항목을 보여준다.
상태: `획득`, `해금`, `미해금`(`???`), `선택`. 획득은 칸 좌상단의 점(`Status Dot` Success)이다. 해금은 점 없는 흰 칸, 미해금은 회색 바탕·실루엣·`???` 이다. 이로치 획득은 점의 툴팁(`이로치 획득`)으로 알린다.
내용: 박스 칸(C-06)처럼 초상 → 이름 → 번호(`#0001`). 칸은 박스 칸과 같은 크기다(2026-09-30 사용자 결정 "도감페이지도 박스처럼 프로필+이름+도감번호", Figma `Dex Layout` `378:1524`).

### C-23 코치마크 말풍선

역할: 튜토리얼의 한 단계를 대상 옆에서 알려준다.

### C-28 파티 상세 기기 창

역할: 개체 하나의 상세를 설정창 옆에 붙은 창으로 보여준다. 도감 기기 창과 같은 방식이다(2026-09-28 사용자 결정 "파티상세페이지도 도감상세처럼 옆에 뜨는거로 바꾸자", 시안 A 기기형).
틀: 폭 380 고정이다. 높이는 내용에 맞춘다. 내용 높이가 바뀌면(글꼴이 늦게 오는 경우 포함) 창 높이를 다시 맞춘다. 도감 기기 창도 같다(`src/renderer/pet.ts`·`dex.ts` `sendSize`). 몸체는 청록 `#0f766e` 이다. 틀은 빨간 도감 기기 창과 같다. 설정창의 오른쪽에 붙고, 자리가 없으면 왼쪽에 붙는다. 설정창을 옮기면 따라간다. 설정창을 닫으면 같이 닫힌다.
내용(위에서 아래로):

1. 머리: `파티` 글자, `✕`.
2. 화면: 자리 줄, 초상, 이름과 성별 아이콘(24), `Lv.N`, 타입 배지. 파티 개체이면 오른쪽 위에 볼 토글(36, 열린 볼 32·닫힌 볼 28)을 둔다. 파티 개체이면 오른쪽 아래에 상태 배지(디버프 다음 버프, 세로)를 둔다. 버프 배지는 C-04 와 같이 남은 시간을 쓴다(`src/renderer/pet.ts` `buffBadge`). 화면 높이는 배지와 무관하다. 그래서 배지가 생겨도 아래 칸이 움직이지 않는다(2026-09-30 사용자 결정).
3. 기록 칸: 경험치·친밀도·만복도·기분 막대 2×2.
4. 돌봄: `밥 주기`·`놀아주기`. 파티 개체만 둔다.
5. 성장 카드: 진화 줄, `도감 보기` 줄. 진화 줄을 누르면 설정창에서 진화 확인 창이 열린다. `도감 보기` 를 누르면 이 기기 창을 닫고 도감 탭에서 그 종의 도감 기기 창을 연다(2026-09-30, 성격 줄 자리). 규칙은 [상세와 진화](game.md#4-상세와-진화)를 따른다. 옛 성격 변경 창 시안은 Figma `06 · 보류·비활성화` 의 `914:23253`·`914:23428`·`914:23624` 다.
6. 크기: 단추 1~`sizeLevels`. 파티 개체만 둔다.
7. 실패 알림: 마지막 실패 문구.

관리 줄(`교체`·`박스에 보관`·`파티에 배치`)은 두지 않는다. 옮기기는 파티 교체 모달에서 끌어 놓아 한다(2026-09-30 사용자 결정).
9. 바닥 조작: `◀ 이전`·`울음소리`·`다음 ▶`. 소리를 끄면 `울음소리`를 막는다.

자리 줄: 파티 개체는 `파티 N번 · 나와 있음` 또는 `파티 N번 · 볼 안`이다. 박스 개체는 `<박스 이름> · 보관 중`이다.
여는 경로: 파티 카드, 박스 칸, 우클릭 메뉴의 `상세 보기`, 진화 배너의 `바로가기`.
닫는 경로: `✕`, Esc, 떠 있는 개체의 카드나 칸을 다시 누르기, 파티·박스 탭 나가기(2026-09-30 사용자 결정 "그냥 해당 탭을 나가면 상세 닫게해."). 같은 탭을 다시 누르면 닫지 않는다. 그 탭으로 돌아와도 다시 열지 않는다. 도감 기기 창도 도감 탭을 나가면 닫히고 고른 칸이 비워진다. 탭을 바꾸는 곳(탭 단추, 튜토리얼, 알림 배너 `바로가기`, 교환 링크, 구매 창 `돌보미집 보기`, 개체 상세 열기)은 모두 `setTab` 을 거친다.
선택 표시: 기기 창에 뜬 개체의 카드나 칸은 옅은 배경(`bg/accent`)이다. 컬러 테두리를 쓰지 않는다.
이전·다음: 파티 개체는 파티 칸 순서, 박스 개체는 박스 순서로 돈다. 방향키 `←`·`→`도 같다.

규칙은 [파티 상세 기기 창](game.md#파티-상세-기기-창)을 따른다. 구현은 `src/main/pet-window.ts`, `src/renderer/pet.html`, `src/renderer/pet.ts` 다.

편지: 머리는 `‹ 제목` 과 `✕` 다. `‹` 는 목록으로 돌아간다. 아래로 `보낸 이 · 날짜`, 본문, 선물 카드다.
선물 카드: 받기 전은 `선물 N` 과 `받기`, 선물 줄(그림·이름·`×개수`)이다. 받은 뒤는 회색 면에 `받은 선물` · `받음`, 흐린 선물 줄, `M월 D일에 받았어요 · 가방에 들어갔어요` 다. 로그인하지 않았으면 `받기` 를 잠그고 아래에 `로그인하면 받을 수 있어요.` 와 `로그인` 을 둔다.
