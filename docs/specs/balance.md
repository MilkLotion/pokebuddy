# 밸런스 수치

이 문서는 가격·적립·성장 같은 밸런스 수치를 모은다. 코드의 규칙표는 이 수치를 따른다. 규칙은 [게임 규칙](game.md), 흐름은 [사용자 시나리오](scenarios.md)를 따른다.

## 읽는 기준

이 문서는 숫자만 모은다. 규칙의 뜻은 기능 계약을 따른다. 숫자는 놀아 보며 고친다. 값을 바꿀 때는 이 문서와 `data/`를 함께 고친다.
시간 값은 ms 정수로 저장한다. 화면 표기는 초·분 단위로 올림한다. [모듈 계약](modules.md#저장-구조)을 따른다.

## 기준점

기준: 하루 4시간 정도 켜 두면 랜덤알 하나를 살 수 있다. 다른 가격은 이 기준으로 정한다.

| 항목 | 값 |
|---|---|
| 포인트 적립 간격 | 개체 1마리당 2분에 1포인트 |
| 친밀도에 따른 단축 | 친밀도 100이면 1분에 1포인트. 최대 2배 |
| 적립 대상 | 파티와 프리셋에 배치한 개체마다 각자 적립한다. 배율은 [적립 배율](#적립-배율)을 따른다. 박스 보관은 멈춘다 |
| 기준 수입 | 1마리 4시간에 120포인트 |
| 포인트 적립 배율 | 버프는 개체의 적립을 빠르게 한다. 배고픔과 심심함은 적립을 느리게 한다. 수치는 [포인트 적립 배율](#포인트-적립-배율)을 따른다 |

## 성장

레벨 곡선은 원작의 성장 속도를 따른다. 종마다 성장 속도를 데이터에 둔다. 원작의 여섯 가지는 빠름, 보통 빠름, 보통 느림, 느림, 불규칙, 변동이다. 100레벨까지 누적 경험치는 약 60만에서 164만이다. 최대 레벨은 100이다.

| 도구 | 경험치 |
|---|---|
| 경험사탕XS | 100 |
| 경험사탕S | 800 |
| 경험사탕M | 3,000 |
| 경험사탕L | 10,000 |
| 경험사탕XL | 30,000 |
| 이상한사탕 | 레벨 1 상승. 새 레벨의 진행은 0부터 |

환산: 보통 빠름 종을 100레벨까지 키우면 약 100만 경험치다. XL 사탕 약 34개이며 10,880P다. 하루 4시간 기준 약 3주다. 작은 사탕은 단가가 비싸며 미세 조정용이다.
데이터: 종별 성장 속도는 `data/species.defaults.json`의 `growthRate`에 있다. 1089종 기준으로 보통 빠름 450, 느림 266, 보통 느림 263, 빠름 67, 불규칙 29, 변동 14다.

## 만복도와 돌봄

시간은 앱 실행 중이며 PC를 쓸 수 있을 때만 흐른다.

| 항목 | 값 |
|---|---|
| 만복도 감소 | 시간당 40. 1분 30초에 1 (2026-10-05 사용자 결정. 그 전에는 시간당 30) |
| 구간 | 배부름 100~60 · 보통 60~40 · 배고픔 40~15 · 매우 배고픔 15~0 |
| 말풍선 | 배고픔(고기 1개)과 매우 배고픔(고기 3개)에 들어가면 띄운다. 머무르면 배고픔 10분, 매우 배고픔 5분마다 다시 띄운다. 한 번에 5초 보인다. 보통 구간에서는 없음 |
| 기본먹이 회복 | 40. 무료이며 무제한 (2026-10-05 사용자 결정. 그 전에는 20) |
| 밥 주기 쿨타임 | 10분. 기본먹이와 프리미엄먹이가 공유 |
| 프리미엄먹이 | 만복도를 100으로 채운다. 든든함이 남은 동안 만복도는 줄지 않는다 |
| 배고픔 디버프 | 배고픔 구간 친밀도 증가량 −30%. 매우 배고픔 −60%. 누적 친밀도는 깎지 않는다 |
| 배고픔 포인트 손해 | 배고픔 −30%. 매우 배고픔 −60% (2026-10-05 사용자 결정 "배고픔효과자체는 너가 얘기한대로 좋은거같긴해"). 셈은 [포인트 적립 배율](#포인트-적립-배율)을 따른다 |

만복도는 시계 시간으로 준다. PC 를 쓸 수 있는 시간을 센다. 에이전트 작업 여부와 상관없다.
환산: 배고픔 구간에서 쿨타임마다 기본먹이를 주면 10분에 약 33씩 오른다.
기본먹이는 크게 늘리지 않는다. 프리미엄먹이의 값어치를 지키기 위해서다(2026-10-05 사용자 "밥먹이는거를 그렇게 늘려버리면 프리미엄 먹이의 가치가 너무 떨어진다").

밥 주기는 만복도가 가득이 아니고 쿨타임이 아니면 언제나 할 수 있다. 개체 상세와 포켓몬 위 우클릭 메뉴에서 한다.

| 신남 (장난감) | +60%. 2시간. 그동안 심심함이 쌓이지 않는다 (2026-10-05 사용자 결정. 그 전에는 +50%) |
| 버프 대상 | 포인트 적립과 친밀도 증가량에 같이 건다. 친밀도와 상관없다. 친밀도가 0 이어도 받는다 |

| 버프 갱신 | 같은 버프를 다시 걸면 남은 시간을 그 지속시간으로 바꾼다. 더하지 않는다. 남은 시간이 더 길면 그대로 둔다. 장난감·프리미엄먹이를 쓰기 전에 가방 미리보기가 남은 시간이 사라진다고 경고한다(2026-10-05) |

| 친밀도 증가 배율 | (100% + 버프)에 만복도 구간 배율(배고픔 70%, 매우 배고픔 40%)을 곱한다. 포인트 적립 배율과 셈이 다르다(2026-10-05 사용자 결정 "친밀도 오르는 비율은 기존처럼 유지하자"). 구현은 `src/state/time.ts` `affinityPercent` 다 |
| 친밀도 시간 획득 | 10분에 1. 표시와 숨김이 같다. 박스 보관은 멈춘다 |
| 친밀도 돌봄 획득 | 밥 주기 2, 놀아주기 3. 쿨타임마다 한 번 |
| 도구의 즉시 친밀도 | 프리미엄먹이 +8. 밥 주기 몫 2를 포함한다. 장난감 +5 (2026-10-05 사용자 결정 "10/15는 너무 큰거같아" 뒤 권장값 "진행") |
| 놀아주기 쿨타임 | 10분. 밥 주기와 따로 센다 |
| 놀아주기 효과 | 친밀도 +3. 심심함 −50 |
| 하루 상한 | 없다 |
| 에이전트 작업 시간 | 친밀도와 포인트를 더 쌓지 않는다(2026-10-05 사용자 결정, 그 전에는 2배). 누적 작업 시간(`totals.workMs`)을 센다. 업적과 로토무 모습 바꾸기가 쓴다. 심심함은 이 시간만큼 한 번 더 쌓인다([심심함](#심심함)). 토큰량은 쓰지 않는다 |

놀아주기 중첩(들뜸·신남 단계)과 놀아주기 상태(20분)는 2026-10-05 에 없앴다(사용자 결정 "2. 진행").
환산: 친밀도 0에서 100까지 30분마다 돌보면 약 5.5시간, 45분마다 돌보면 약 6.9시간이다. 돌보지 않으면 약 38.9시간이다. 매우 배고픔의 −60% 가 오래 이어지기 때문이다(2026-10-05 모의 계산, 1분 단위).
친밀도가 오르면 포인트 적립 간격이 2분에서 1분으로 짧아진다.

## 적립 배율

개체 하나의 적립 속도에 곱하는 배율이다(2026-10-05 사용자 결정). 규칙은 [파티 표시와 박스 보관](game.md#파티-표시와-박스-보관)을 따른다. 구현은 `src/state/rules.ts` `TIME_RULES.otherPresetPointPercent` 다.

| 상태 | 배율 | 버프·손해 |
|---|---|---|
| 적용한 프리셋(꺼냄·볼 안) | 100% | 받는다 |
| 적용하지 않은 프리셋 | 20% | 받지 않는다. 게이지와 버프 시간이 멈춰 있다 |
| 박스 | 0% | — |

환산: 친밀도 100인 1마리는 다른 프리셋에서 시간당 12P다. 다른 프리셋 4개(24마리)를 모두 채우면 시간당 최대 288P다.

## 포인트 적립 배율

적용한 프리셋의 개체는 버프와 손해를 적립 속도에 더한다(2026-10-05 사용자 결정 "-30% -60%로 보기편하게", "더하는 방식으로"). 곱하지 않는다. 친밀도와 상관없이 건다. 구현은 `src/state/time.ts` `pointPercent`·`pointParts` 다.

포인트 적립 배율 = 100% + 버프 − 손해. 바닥은 10%다.
포인트 적립 속도 = 기본 속도 × 친밀도에 따른 단축 × 포인트 적립 배율.

| 항목 | 값 |
|---|---|
| 든든함 | +60% |
| 신남 (장난감) | +60% |
| 배고픔 | −30% |
| 매우 배고픔 | −60% |
| 심심해 | −10% |
| 지루해 | −20% |
| 최대 | 220%. 든든함과 신남(장난감)이 함께일 때다 |
| 바닥 | 10% |

다른 프리셋의 개체는 이 배율을 받지 않는다. [적립 배율](#적립-배율)의 20% 만 받는다.
파티 상세 기기 창의 `포인트 적립` 줄이 합과 내역을 보인다. 문구는 [파티 상세 기기 창](ui-components.md#c-28-파티-상세-기기-창)을 따른다.
이 규칙은 기분과 돌봄 보너스를 대신한다. 돌봄 보너스는 친밀도 100인 개체만 받았다(2026-10-02 결정, 2026-10-05 삭제).

환산(2026-10-05 모의 계산): 친밀도 100인 1마리가 혼자 일하는 8시간을 1분 단위로 셈했다. 값은 도구 값을 뺀 시간당 수입이다.

| 돌보는 간격 | 돌봄만 |
|---|---|
| 30분 | 60P |
| 1시간 | 60P |
| 1시간 30분 | 44P |
| 2시간 | 36P |
| 돌보지 않음 | 23P |

밥 주기·놀아주기는 버프 없이 손해만 막는다. 1시간 안에 돌보면 버프와 손해가 없는 시간당 60P 다. 장난감을 쓰면 30분·1시간 간격에서 86P, 2시간 간격에서 64P 다. 장난감과 프리미엄먹이를 함께 쓰면 최대 약 97P 다 (2026-10-05 사용자 결정 "b로 하자").

## 심심함

심심함은 일한 시간만큼 쌓이는 값이다(2026-10-05 사용자 결정, 이름 "심심함이 제일 나은거같네"). 만복도와 재는 기준이 다르다(사용자 "떨어지는 수치가 만복도랑 다르게 측정하고싶어"). 기분을 대신한다. 구현은 `src/state/rules.ts` `BOREDOM_RULES` 다.

| 항목 | 값 |
|---|---|
| 범위와 시작 | 0~100. 높을수록 심심하다. 새 개체는 0 |
| 쌓임 | 시간당 +30. 2분에 1 |
| CLI 작업 | 연결한 CLI 가 작업한 시간은 한 번 더 센다. 그동안 시간당 +60 |
| 놀아주기 | −50 |
| 장난감 | 0 으로 만든다. 신남(장난감)이 남은 2시간 동안 쌓이지 않는다 |
| 단계 | 보통 50 미만 · 심심해 50 이상 · 지루해 80 이상 |
| 포인트 손해 | 심심해 −10%. 지루해 −20% (2026-10-05 사용자 결정 "심심해 / 지루해 2스텝으로 -10 -20") |
| 친밀도 속도 | 영향 없음 |
| 말풍선 | 심심해와 지루해에 들어가면 장난감 공을 띄운다. 머무르면 심심해 10분, 지루해 5분마다 다시 띄운다. 규칙은 [배고픔 상태 표시](game.md#배고픔-상태-표시)를 따른다 |
| 시간이 흐르는 곳 | 파티 칸 개체. 숨김도 같다. 다른 프리셋과 박스 보관은 멈춘다 |

단계 경계 50·80 과 말풍선 간격은 Claude 의 제안이다. 사용자가 정리 표를 확정했다(2026-10-05 "제안한 대로 이정도정리하면 좋을거같네").
환산: 혼자 일하면 0에서 심심해까지 1시간 40분, 지루해까지 2시간 40분이다. CLI 가 계속 작업하면 심심해까지 50분, 지루해까지 1시간 20분이다.
혼자 일할 때 지루해의 손해는 거의 걸리지 않는다(2026-10-05 모의 계산). 심심함의 주 역할은 말풍선으로 놀아 달라고 조르는 것이다.

판정은 마리마다 따로 한다. 항목 가중치와 포인트 양은 2026-09-29 사용자 결정이다. 주울 확률은 2026-10-05 사용자 결정이다. 2026-09-29 결정은 앞선 "도구 하루 5번·포켓몬 3일에 1번"과 "10분마다 20%"를 대신한다. 그 밖의 값은 제안이다. 사용자가 확인하기 전이다.

| 항목 가중치 | 주웠을 때 포인트 100 · 도구 50 · 진화용 도구 20 · 포켓몬 1. 포켓몬 수집 난이도 가중치를 따른다 | 2026-09-29 사용자 결정 |

## 서버 검증 상한

서버가 올린 저장을 직전 서버 저장과 견줄 때 쓰는 상한이다([서버 저장 검증](modules.md#서버-저장-검증)). 상한은 규칙상 정상 최대치에 여유 1.1 을 곱한다. 틈 Δt 는 서버 시각이고 72시간에서 자른다. 파일 쓰기(15초)·틱(30초) 지연 때문에 Δt 에 60초를 더한다.
