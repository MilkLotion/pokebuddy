# 조작 계약

이 문서는 개체·아이템을 바꾸는 조작의 공통 규칙이다. 교체, 옮기기, 고르기, 아이템 사용·판매·구매, 진화·모습 바꾸기, 교환, 알 열기가 대상이다.

## 범위와 근거

- 2026-10-10 조작 전수 점검의 결과다. 점검은 89개 기능을 보았다. 사용자는 아래 결정을 내렸다.
  - "교체·고르기 모달은 누르기만" — 모달에서 끌어 놓기를 뺀다.
  - "고르기 풀림" — 모달에서 칸을 골라 바꾸면 고르기가 풀린다.
  - "우클릭 `옮기기` 로 들기" — 탭 화면의 칸 순서를 누르기로도 바꾼다.
  - "확인 창 두지 않음" — 덮어쓰는 조작에 확인 창을 더하지 않는다.
  - 시안 확인 "진행해봐" — 호버·고름 색, 떠 있는 실패 배너, `옮기기` 메뉴, 판매 결과, 지금 보는 줄 표시.
- 각 기능의 세부 규칙은 기능 스펙에 있다. 이 문서는 공통 규칙과 기능 목록만 적는다.
- Figma 근거는 00 `호버·고름 기준 (2026-10-10)`과 05 의 각 화면이다.

## 공통 규칙

### 입력

- 교체·고르기 모달은 누르기만 받는다. 파티 교체, 배틀 파티 교체, 기술 바꾸기, 교환이 해당한다. 끌어 놓기는 없다.
- 탭 화면의 칸 순서는 끌어 놓기와 누르기 둘 다로 바꾼다. 파티 탭 칸, 모험 탭 칸, 박스 칸, 박스 순서 타일이 해당한다.
- 누르기 방식은 우클릭 메뉴의 `옮기기`다. 고르면 그 칸을 든다. 놓을 칸을 누르면 끌어 놓기와 같은 명령을 보낸다.
- 끌어 놓기로만 되는 일은 두지 않는다.
- 좌클릭은 상세를 열고, 우클릭은 메뉴를 연다. 파티 카드, 박스 칸, 모험 탭 칸이 같다.

### 고르기 (모달)

- 자리를 먼저 고르고, 넣을 것을 누른다.
- 고른 칸은 톤 바탕이다. 같은 칸을 다시 누르면 고르기가 풀린다.
- 바꾸기가 성공하면 고르기가 풀린다. 바꾸기가 실패하면 고르기를 그대로 둔다.
- 고른 칸이 없으면 판의 개체는 누를 수 없다. 칸 이름에 `오른쪽에서 넣을 칸을 먼저 누르세요`를 보인다. 기술 바꾸기는 예외다. 고른 칸이 없을 때 목록을 누르면 상세 칸만 바뀐다.
- 칸을 빼거나 보관하는 일은 "칸 고르기 → 판의 박스 빈 칸 누르기"다. 파티 교체는 보관(`party.keep`), 배틀 파티 교체는 빼기(`battle.clear`)다.

### 들기 (`옮기기`)

- 든 칸은 흐리다. 커서를 따라가는 칸이 뜬다.
- 놓을 칸은 가리키면 초록 톤이다.
- 같은 칸, 칸 밖을 누르거나 Esc 를 누르면 내려놓는다.
- 박스 탭, 파티 탭, 모험 탭, 박스 순서 모달이 같은 부품(`src/renderer/manage/box-move.ts`)을 쓴다.

### 상태 표시

- 가리킴(호버)은 한 단계 진한 중립 회색이다. 흰 칸·카드·보조 단추는 `bg/canvas`, 바탕이 `bg/canvas` 인 칸은 그보다 한 단계 진하다.
- 고름·찾음·놓을 칸은 초록 톤(`bg/accent`)이다. 가리킴과 같은 색을 쓰지 않는다.
- 기술 바꾸기 목록에서 상세 칸에 보이는 줄은 중립 톤(`border/default`)이다.
- 호버 규칙은 한 곳에 둔다. 설정창은 `styles/manage/widgets.css`, 기기 창은 `styles/device.css`다. 새 칸·카드·단추도 여기에 더한다.
- 답이 0.3초 넘게 없으면 처리 중 점 세 개를 단다. 누른 단추, 끌어 놓은 칸, 다시 그린 화면의 같은 단추에 단다.
- 색 테두리로 강조하지 않는다.

### 결과와 실패

- 결과는 이미 있는 자리의 글자·색을 바꿔 보인다. 줄을 새로 끼우지 않는다. 화면 크기와 자리는 바뀌지 않는다.
- 실패 문구의 자리는 아래와 같다.

| 곳 | 실패 문구 자리 |
|---|---|
| 바닥 단추 줄이 있는 모달 | 바닥 줄의 빈자리. 빨간 점과 글자 |
| 바닥 단추 줄이 없는 모달 | 모달 아래쪽 안에 떠 있는 실패 배너 |
| 탭 화면(파티·모험) | 창 아래쪽에 떠 있는 실패 배너. 4초 뒤 사라진다. ✕ 로 닫는다 |
| 박스 탭 | 머리 부제 자리 |
| 기기 창 | 자리 줄 또는 합계 상자 |

- 떠 있는 실패 배너는 02 `Alert` Tone=Error·Type=Banner 다. 자리를 밀지 않는다.
- 상태가 이어지는 동안 늘 보이는 안내(예: 교환이 닫힘)는 본문에 둔다. 누를 때마다 생겼다 사라지는 것이 아니기 때문이다.
- 처리 중에 다시 누른 입력은 받지 않는다.

### 확인 창

- 되돌릴 수 없는 일만 확인 창을 거친다. 진화, 한 방향 모습 바꾸기, 포켓몬 팔기가 해당한다.
- 덮어쓰는 조작은 확인 없이 바로 한다. 기존 파티 가져오기, `모두 빼기`, `모두 박스로`, 교환 `나가기`가 해당한다.

### 모달과 기기 창

- 기기 창이 다른 개체로 넘어가면 앞 개체에 묶인 모달을 닫는다. 진화, 모습 바꾸기, 메가진화, 기술 바꾸기, 팔기 모달이 해당한다. 지난 실패 문구도 지운다.
- 그리는 중에 대상이 사라져 모달을 닫을 때는 실패 문구를 남긴다. 기기 창 자리 줄에 보인다.
